# 外汇兑换接口总览

外汇兑换渠道用于将一种货币的余额兑换为另一种货币。兑换是异步的，分为三个步骤：

1. **获取报价** — 调用[获取报价](./quote)锁定执行汇率并获得 `quote_id`。报价与您绑定，并在一个较短的时间窗口后过期。
2. **提交兑换订单** — 使用该 `quote_id` 和您自己的 `client_order_id` 调用[提交兑换订单](./submit)发起兑换。是否受理会同步返回，但兑换本身为异步处理。
3. **查询兑换订单** — 使用相同的 `client_order_id` 轮询[查询兑换订单](./query)，直到订单到达终态（成功或失败）。

## 错误码

| 错误码 | 说明                                             |
| ------ | ------------------------------------------------ |
| 603001 | 参数错误                                         |
| 603002 | 不支持的货币对                                   |
| 603004 | 报价不存在                                        |
| 603005 | 报价已过期（请重新报价）                         |
| 603006 | 报价已被使用（请重新报价）                       |
| 603007 | 可兑换余额不足                                   |
| 603008 | 未授权 / 无兑换权限 / 非服务时段                 |
| 603009 | 订单不存在                                        |
| 603010 | 服务暂时不可用，请稍后重试                       |
