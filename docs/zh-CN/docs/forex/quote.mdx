该接口用于获取外汇兑换报价。返回的报价会锁定一个短时间窗口内的执行汇率，在窗口内提交即可按该汇率成交。

<CliCommand>
longbridge forex quote USD HKD --amount 1000
</CliCommand>

<SDKLinks module="forex" klass="ForexContext" method="quote" />

### Parameters

> Content-Type: application/json; charset=utf-8

| Name          | Type   | Required | Description                                                               |
| ------------- | ------ | -------- | ------------------------------------------------------------------------- |
| from          | string | YES      | 转出货币，ISO 4217，例如：`USD`                                           |
| to            | string | YES      | 转入货币，例如：`HKD`                                                     |
| amount        | string | 条件必填 | 转出金额。`amount` / `target_amount` 二者必填其一。最多 2 位小数，最小 `0.01` |
| target_amount | string | 条件必填 | 转入金额。`amount` / `target_amount` 二者必填其一。                       |

请求示例：

```json
{ "from": "USD", "to": "HKD", "amount": "1000.00" }
```

报价与您绑定，只能由您本人提交。

```cpp
#include <iostream>
#include <longbridge.hpp>

#ifdef WIN32
#include <windows.h>
#endif

using namespace longbridge;
using namespace longbridge::forex;

static void
run(const OAuth& oauth)
{
    Config config = Config::from_oauth(oauth);
    ForexContext ctx = ForexContext::create(config);

    ctx.quote("USD", "HKD", Decimal(1000.0), std::nullopt, [](auto res) {
        if (!res) { std::cout << "failed" << std::endl; return; }
        std::cout << "rate: " << res->rate << std::endl;
    });
}

int main(int argc, char const* argv[]) {
#ifdef WIN32
    SetConsoleOutputCP(CP_UTF8);
#endif

    const std::string client_id = "your-client-id";
    OAuthBuilder(client_id).build(
    [](const std::string& url) {
        std::cout << "Open this URL to authorize: " << url << std::endl;
    },
    [](auto res) {
        if (!res) {
            std::cout << "authorization failed: " << *res.status().message() << std::endl;
            return;
        }
        run(*res);
    });

    std::cin.get();
    return 0;
}
```

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/longbridge/openapi-go/config"
	"github.com/longbridge/openapi-go/forex"
	"github.com/longbridge/openapi-go/oauth"
	"github.com/shopspring/decimal"
)

func main() {
	o := oauth.New("your-client-id").
		OnOpenURL(func(url string) { fmt.Println("Open this URL to authorize:", url) })
	if err := o.Build(context.Background()); err != nil {
		log.Fatal(err)
	}
	conf, err := config.New(config.WithOAuthClient(o))
	if err != nil {
		log.Fatal(err)
	}
	fctx, err := forex.NewFromCfg(conf)
	if err != nil {
		log.Fatal(err)
	}
	defer fctx.Close()
	amount := decimal.NewFromFloat(1000)
	resp, err := fctx.Quote(context.Background(), &forex.GetForexQuote{
		From:   "USD",
		To:     "HKD",
		Amount: &amount,
	})
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("rate:", resp.Rate)
}
```

## Response

### Response Headers

- Content-Type: application/json

### Response Example

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "ok": true,
    "quote_id": "Q20260925000123",
    "rate": "7.7812",
    "expire_at": 1790000000000,
    "ccy_pair": "USD/HKD"
  }
}
```

`data` 字段说明：

| Name      | Type   | Description                                                                             |
| --------- | ------ | --------------------------------------------------------------------------------------- |
| quote_id  | string | 报价 id，提交订单时使用                                                                  |
| rate      | string | 客户执行汇率（标准货币对表示；1 BASE = rate QUOTE）。在窗口内的订单按此汇率成交          |
| expire_at | int64  | 报价过期时间，Unix 毫秒时间戳                                                            |
| ccy_pair  | string | 汇率对应的标准货币对，格式为 BASE/QUOTE；与请求的 `from`/`to` 方向无关（HKD→USD 与 USD→HKD 均返回 USD/HKD） |

### Response Status

| Status | Description              | Schema |
| ------ | ------------------------ | ------ |
| 200    | 报价获取成功。           | None   |
| 400    | 请求参数错误，请求被拒绝。 | None   |
