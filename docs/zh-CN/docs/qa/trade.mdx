## Q1: 支持哪些订单类型？

模拟账户和真实账户均支持普通限价单、市价单及到价买入、到价卖出等条件订单，暂不支持附加订单。网格订单可通过[网格交易](/zh-CN/docs/trade/grid/overview) API 使用。

## Q2: 模拟账户交易时间有哪些？

本问题仅适用于 Longbridge 香港 / 新加坡模拟账户。

模拟账户港股时间与真实环境相同，美股暂未支持盘前盘后交易，仅支持常规交易时段模拟撮合。

## Q3: 如何进美股夜盘交易？

委托下单接口通过 `outside_rth` 参数传递 [OVERNIGHT](/docs/trade/order/submit#parameters) 枚举即为指定夜盘交易的订单。

## Q4: 模拟账户下的交易规则？

本问题仅适用于 Longbridge 香港 / 新加坡模拟账户。

模拟账户支持港美股股票、ETF、港股轮证、美股期权交易。美股盘前盘后交易在模拟账户下不支持。

模拟交易参考真实市场买卖摆盘进行撮合，即当委托买入价高于等于摆盘卖一价、委托卖出价低于等于摆盘买一价，即可撮合成交，市价单默认均可成交。

## Q5: 如何重置模拟账户资金？

暂不支持用户手动重置模拟资金，如有需求可联系您的客服或客户经理，进行线下处理。

## Q6: 通过 OpenAPI 下单后，我如何看到订单？

经 OpenAPI 委托订单后，可通过以下方式查看订单：

- **订单查询接口**：调用 API 查询订单实时状态
- **WebSocket 推送**：订阅交易推送，实时接收订单更新
- **CLI**：通过 [Longbridge CLI](/docs/cli) 在命令行查询，例如 `longbridge orders`
- **App / PC**：直接在终端产品中查看对应账户下的订单及其状态

## Q7: 如何知道账户资金是否足够交易？

可调用交易类接口 `/v1/trade/estimate/buy_limit` 获取账户现金可买、融资可买及可卖空的数量，因系统风控要求逻辑复杂，不建议自己计算可交易数量。

## Q8: 下单接口返回"用户认证失败"什么意思？

通常是对应交易业务的权限暂未开通，例如期权、美股卖空等。可通过 App 委托挂单引导的权限开通流程，完成权限开通后，继续通过 OpenAPI 完成交易或其他操作。

## Q9: 美股期权交易是否支持盘前交易？

盘前期权暂不支持，目前正在规划中。包括多腿期权也会一起推出，后续推出后我们会更新文档。

## Q10: 如何平仓？

平台没有专门的平仓接口，下单请求里也没有开仓、平仓标记。平仓就是提交一笔与持仓方向相反的普通订单：

1. 用该标的调用 `stock_positions`，读取 `available_quantity`（不是 `quantity`）。为 `0` 说明没有可平仓位。
2. 正数是多头，提交 `Sell` 订单；负数是空头，提交 `Buy` 订单回补。数量取绝对值。
3. 盘中用市价单（`MO`）。美股盘前、盘后不接受市价单，改用最新价提交限价单（`LO`），并把 `outside_rth` 设为 `ANY_TIME`。传入唯一的 `client_request_id`，避免重试时把仓位平两遍。

提交数量超过 `available_quantity` 时，多出的部分会变成反向开仓。各语言 SDK 的完整可运行示例见[平仓](/zh-CN/docs/trade/order/close_position)。

## Q11: 美股碎股下单为什么返回错误码 603200？

美股碎股订单（例如数量为 `0.05`）仅支持在常规交易时段交易，下单时必须将 `outside_rth` 设为 `RTH_ONLY`。不传 `outside_rth` 或传 `ANY_TIME` 时，订单会被拒，返回 HTTP 500 和错误码 `603200`。返回中的 `cancel` / `evaluate` 字段来自 App 内的提示，无需进行任何评估。将 `outside_rth` 设为 `RTH_ONLY` 后重新提交即可。
