获取 access token 所属账户的风险测评档案：最近一次测评的风险等级与得分、专业投资者（PI）状态，以及 `approvals` 中各项的状态。

以下字段的取值由账户系统定义，而非本接口定义，接口原样返回：

- `risk` 是最近一次测评的风险等级字符串（例如 `A5`）。本接口不定义等级集合，也不定义等级之间的顺序，请勿据此推断风险承受能力的高低。
- `pi` 是专业投资者状态码。本接口不定义其取值含义，请当作不透明标识处理。
- `pi_end_at` 与 `deadlines` 是服务端返回的原始整数。本接口不定义其单位（秒或毫秒），将非 0 值转换为时间之前请先确认单位。

`approvals` 与 `deadlines` 都以项为键。`approvals` 的值是字符串而非布尔值：`is_corporate_client` 返回 `"false"` / `"true"`，请比较字符串，不要直接做真假判断。

整数字段可能以 JSON 字符串返回（例如 `"pi_end_at": "0"`），这是网关按 proto3 JSON 序列化 int64 的方式。官方 SDK 两种形式都能解析，并统一以整数暴露。

#include <iostream>
#include <longbridge.hpp>

#ifdef WIN32
#include <windows.h>
#endif

using namespace longbridge;
using namespace longbridge::trade;

static void
run(const OAuth& oauth)
{
    Config config = Config::from_oauth(oauth);
    TradeContext ctx = TradeContext::create(config);

    ctx.risk_assessment([](auto res) {
        if (!res) { std::cout << "failed" << std::endl; return; }
        std::cout << "risk: " << res->risk << std::endl;
    });
}

int main(int argc, char const* argv[]) {
#ifdef WIN32
    SetConsoleOutputCP(CP_UTF8);
#endif

    const std::string client_id = "your-client-id";
    OAuthBuilder(client_id).build(
    [](const std::string& url) {
        std::cout << "Open this URL to authorize: " << url << std::endl;
    },
    [](auto res) {
        if (!res) {
            std::cout << "authorization failed: " << *res.status().message() << std::endl;
            return;
        }
        run(*res);
    });

    std::cin.get();
    return 0;
}

package main

import (
	"context"
	"fmt"
	"log"

	"github.com/longbridge/openapi-go/config"
	"github.com/longbridge/openapi-go/oauth"
	"github.com/longbridge/openapi-go/trade"
)

func main() {
	o := oauth.New("your-client-id").
		OnOpenURL(func(url string) { fmt.Println("Open this URL to authorize:", url) })
	if err := o.Build(context.Background()); err != nil {
		log.Fatal(err)
	}
	conf, err := config.New(config.WithOAuthClient(o))
	if err != nil {
		log.Fatal(err)
	}
	tctx, err := trade.NewFromCfg(conf)
	if err != nil {
		log.Fatal(err)
	}
	defer tctx.Close()
	ra, err := tctx.RiskAssessment(context.Background())
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%+v\n", ra)
}

## Schemas

### risk_assessment_rsp

<a id="schemarisk_assessment_rsp"></a>

| Name                 | Type     | Required | Description                                                                                                                       |
| -------------------- | -------- | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| risk                 | string   | 否       | 最近一次测评的风险等级，例如 `A5`。原样返回；本接口不定义等级集合，也不定义等级之间的顺序。可能为空。                              |
| pi                   | int32    | 否       | 专业投资者（PI）状态码，原样返回。本接口不定义其取值含义。                                                                         |
| approvals            | object   | 否       | 各项的状态，以项名为键、字符串为值，例如 `car` / `cka` / `risk_audit` → `pass`。值是字符串而非布尔值：`is_corporate_client` 返回 `"false"` / `"true"`。 |
| re_authentication    | string   | 否       | 重新认证标记，原样返回。可能为空。                                                                                             |
| pi_end_at            | int64    | 否       | 专业投资者状态的结束时间，以原始整数返回，未设置时为 `0`。本接口不定义其单位（秒或毫秒）。可能以 JSON 字符串返回。                 |
| deadlines            | object   | 否       | `deadlines` 中各项的值，以项名为键、整数为值。为原始整数，单位与 `pi_end_at` 一样未被定义。                                          |
| risk_assessment_at   | string   | 否       | 服务端返回的最近一次测评日期，例如 `2026-10-14`。可能为空。                                                                        |
| score                | int32    | 否       | 测评得分                                                                                                                           |
| strategy_risk_levels | string[] | 否       | 账户的策略风险等级                                                                                                                 |
