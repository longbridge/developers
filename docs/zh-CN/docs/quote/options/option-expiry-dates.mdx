获取标的的期权到期日列表。

请先调用本接口获取有效的 `expiry_date`，再用于[期权链](./option-chain)（`POST /v1/quote/options/strikes`）。

<CliCommand>
# 列出 AAPL 期权的全部到期日
longbridge option chain AAPL.US
</CliCommand>

<SDKLinks module="quote" klass="QuoteContext" method="option_chain_expiry_date_list" />

## 请求

<table className="http-basic">
<tbody>
<tr><td className="http-basic-key">HTTP 方法</td><td>POST</td></tr>
<tr><td className="http-basic-key">HTTP URL</td><td>/v1/quote/options/expiry-dates</td></tr>
</tbody>
</table>

### 请求参数

| 名称   | 类型   | 必填 | 描述                                                       |
| ------ | ------ | ---- | ---------------------------------------------------------- |
| symbol | string | 是   | 正股标的代码，使用 `ticker.region` 格式，例如：`AAPL.US`   |

### 请求示例

<Tabs groupId="request-example">
  <TabItem value="curl" label="cURL" default>

```bash
curl -X POST "https://openapi.longbridge.com/v1/quote/options/expiry-dates" \
  -H "Authorization: Bearer <token>" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{
    "symbol": "AAPL.US"
  }'
```

  </TabItem>
</Tabs>

## 响应

### 响应头

- Content-Type: application/json

### 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "expiry_date": [
      "20261023",
      "20261026",
      "20261030",
      "20261106",
      "20261120",
      "20261218",
      "20270115"
    ]
  }
}
```

列表中可能仍包含刚过期的日期，选用前请与当前日期比较。

### 响应状态

| 状态码 | 描述       | Schema                                                              |
| ------ | ---------- | ------------------------------------------------------------------- |
| 200    | 成功       | [option_expiry_dates_response](#schemaoption_expiry_dates_response) |
| 500    | 服务端错误 | 无                                                                  |

## Schemas

### option_expiry_dates_response

<a id="schemaoption_expiry_dates_response"></a>

| 名称        | 类型     | 必填 | 描述                                |
| ----------- | -------- | ---- | ----------------------------------- |
| expiry_date | string[] | true | 期权到期日列表，使用 `YYYYMMDD` 格式 |
