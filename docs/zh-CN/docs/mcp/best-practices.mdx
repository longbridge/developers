# 安全最佳实践

## 安全建议

- **最小权限**：授权时仅同意当前任务所需的 scope，避免过度授权
- **交易确认**：所有下单类工具都会先以预演（dry run）方式执行，需你明确确认后才会真正提交（见[下单确认机制](/zh-CN/docs/mcp/trading#下单确认机制)）；尽管如此，仍建议在提示词中要求 AI 执行前先向你确认
- **凭证安全**：OAuth 凭证由客户端管理，避免将其复制到不受信任的环境
- **定期审查**：定期在 [Longbridge 账户](https://longbridge.com/hk/download)安全设置中检查并移除不再使用的授权（移除后无法再续期，已签发的 Token 在过期前仍然有效）

## 推荐使用方式

1. **从只读能力开始**：优先使用[行情查询](https://longbridge.com/markets)、账户概览、持仓查看等低风险功能，熟悉工具行为
2. **先用模拟账户练习**：使用模拟账户授权，在不动用真实资金的情况下演练下单流程
3. **逐步开放交易能力**：确认权限范围和风控逻辑后，再使用下单相关工具
4. **在提示词中加入约束**：例如"每笔交易金额不超过 X"、"下单前先向我确认"等明确限制
