# 用 AI 交易股票和期权

将 Claude Code、Codex、Cursor 或其他 MCP 客户端连接到你的 Longbridge 账户后，即可用自然语言研究市场、查看持仓、分析期权链，并对美股、港股的股票、ETF、期权和基金下单。

本指南介绍从接入客户端到完成首笔下单的完整流程。

## AI 可以通过 Longbridge 交易股票吗？

可以。Longbridge MCP 会将自然语言指令转换为真实的券商订单。在准备交易前，AI 可以查询你的购买力、持仓、实时行情和未成交订单。支持的订单功能包括：

- **订单类型**：限价单、市价单、触价限价单 / 触价市价单，以及按金额或百分比的跟踪止损单。港股还支持增强限价单、竞价单和碎股单
- **交易时段**：常规交易时段、美股盘前盘后，以及美股夜盘
- **止盈止损**：可为订单附加止盈、止损，或同时附加两者（括号单）
- **订单管理**：修改未成交订单的价格或数量，或撤单
- **有效期**：当日有效、撤单前有效、指定日期前有效

每笔订单都需经过[两步确认](#下单确认机制) —— 在你确认具体订单之前，任何指令都不会发送到交易所。

## AI 能用你的 Longbridge 账户做什么？

授权后，AI 可代你使用 [190+ 工具](/zh-CN/docs/mcp/tools)，包括：

- 美股、港股、A 股的实时报价、K 线、盘口深度和资金流向
- 账户余额、持仓、盈亏分析、订单、成交记录和结单
- 基本面、估值、分析师评级、新闻和公告
- 期权链、含隐含波动率和希腊值的期权报价，以及看跌 / 看涨成交量
- 附带止盈 / 止损的股票订单
- 以单笔订单提交的期权多腿策略
- 基金下单、定投（DCA）计划、网格交易和股价提醒

访问范围仅限于你账户已开通的市场、产品和权限，以及你授予的 OAuth scope。

## 将 AI 客户端连接到 Longbridge

你需要：

- 已完成开户的 [Longbridge 账户](https://longbridge.com/hk/download)，或模拟账户
- 支持交易的 MCP 客户端 —— Claude Code、Codex、Cursor、Zed，或其他直接连接 `https://mcp.longbridge.com` 的客户端

:::warning ChatGPT 与 Claude 连接器为只读
Longbridge ChatGPT App 与 Claude 目录连接器不含交易工具。可用它们进行研究和账户查询；如需下单，请使用直接连接的客户端。
:::

### 第 1 步：添加 Longbridge MCP 服务

以 Claude Code 为例：

```bash
claude mcp add --transport http longbridge https://mcp.longbridge.com
```

其他客户端请参见[客户端接入](/zh-CN/docs/mcp/setup)。

### 第 2 步：使用 Longbridge 账户授权

在 Claude Code 中输入 `/mcp`，选择 `longbridge`，再选择 **Authenticate**。浏览器会打开 Longbridge 登录页 —— 登录并同意所请求的权限即可。整个过程无需在对话中粘贴任何 API 密钥或 Token。详见[授权](/zh-CN/docs/mcp/authorization)。

### 第 3 步：验证连接

向 AI 提一个需要读取账户的问题：

```text
查看我的 Longbridge 账户余额和购买力。
```

如果返回了现金和购买力，说明已连接成功。

## 研究市场与持仓

AI 将对话与实时行情、账户数据结合在一起，你可以连续追问，无需切换应用。

```text
列出我当前的持仓、今日盈亏，以及哪只股票波动最大。
```

```text
对比 NVDA.US、AMD.US 和 700.HK 的当前价格、市盈率和今日涨跌幅。
```

```text
总结 TSLA.US 的最新新闻和分析师评级变化。
```

AI 还可以查询你的未成交订单、历史订单、成交记录、资金流水和月结单。

## 交易股票和 ETF

描述你想下的订单，AI 会准备好订单并在发送前向你展示预览。

```text
以 200 美元限价买入 10 股 AAPL.US，当日有效。
```

```text
以市价买入 100 股 QQQ.US，止盈价 560 美元，止损价 480 美元。
```

```text
列出我的未成交订单，并撤销 TSLA.US 的限价单。
```

如需在盘前盘后交易，请明确说明：

```text
准备一笔限价单，以 170 美元买入 5 股 NVDA.US，允许在盘前盘后成交。提交前先给我看订单详情。
```

不确定能买多少？可以先问：

```text
按我当前的购买力，以 420 美元的价格最多能买多少股 MSFT.US？
```

## 下单确认机制

所有下单、改单、撤单工具默认以**预演（dry run）**方式运行：

1. AI 调用下单工具但不实际执行。Longbridge 校验订单并返回预览，附带一个三位数的**确认码** —— 此时订单不会到达交易所。
2. AI 向你展示预览：标的、方向、数量、价格、订单类型和交易时段。
3. 只有在你明确确认后，AI 才会携带确认码再次调用工具，订单才会被发送。

确认码仅可使用一次，10 分钟内有效，且与该笔订单绑定 —— 任何字段发生变化都需要重新预览。这可以防止误下单或因误解指令而下单。

## 交易期权与分析期权链

AI 可以浏览到期日和行权价，并获取你关注的合约报价，包括隐含波动率和希腊值。

```text
查看 AAPL.US 下周五到期的期权链，只看看涨期权，行权价在当前价格上下 5% 以内。
```

```text
查看 AAPL.US 下周五到期、行权价 250 美元的看涨期权的 delta、gamma、theta 和隐含波动率。
```

```text
NVDA.US 今天的看跌 / 看涨成交量比是多少？哪些合约最活跃？
```

准备好后，单腿期权订单与股票订单一样，遵循先预览、后确认的流程。

## 构建期权多腿策略

Longbridge 原生支持多腿订单，策略的所有腿作为一笔订单提交，并以单一净价格同时成交。支持的策略包括：

- 看涨 / 看跌垂直价差
- 跨式和宽跨式
- 看涨 / 看跌日历价差
- 备兑看涨、备兑看跌和领口策略

```text
为 SPY.US 构建两周后到期的牛市看涨价差：买入 580 美元看涨期权，卖出 590 美元看涨期权。下单前先给我看各腿明细、净支出以及最大盈利和最大亏损。
```

可用策略取决于你账户的期权交易等级。

## 股票和期权之外

同一连接还支持：

- **基金**：浏览基金、查看业绩和持仓，并提交基金申购或赎回订单
- **定投计划**：创建、暂停、恢复或修改定期定额投资
- **网格交易**：设置在价格区间内自动低买高卖的网格订单
- **股价提醒**：当股票突破某个价格或涨跌超过一定百分比时收到通知

```text
创建一个月度定投计划，每月 1 日投资 500 美元买入 VOO.US。
```

```text
当 NVDA.US 跌破 160 美元时提醒我。
```

## 使用模拟账户练习

还没准备好用真金白银交易？使用模拟账户授权 Longbridge MCP，即可用模拟资金演练研究、构建订单、确认和撤单的完整流程。使用真实账户授权时，订单均为真实的券商订单。

## 为什么将 AI 连接到 Longbridge？

- **从研究到执行一次对话完成**：行情、基本面、持仓上下文、构建订单、预览和执行，无需切换应用
- **多市场覆盖**：一个账户即可交易美股、港股的股票、ETF、期权、涡轮和基金
- **内置安全机制**：每笔订单都需要你明确确认具体订单内容，且由你决定授予 AI 哪些权限
- **无需 API 密钥**：标准 OAuth 2.1 登录，可随时在账户安全设置中撤销

## 常见问题

### AI 可以通过 Longbridge 交易股票吗？

可以。直接连接 Longbridge MCP 服务的客户端（如 Claude Code、Codex、Cursor）可以对美股和港股的股票、ETF 下单、改单和撤单。

### AI 可以通过 Longbridge 交易期权吗？

可以，包括单腿订单和多腿策略，具体取决于你账户的期权交易等级。

### 可以在 ChatGPT 或 Claude 应用中交易吗？

暂不支持。Longbridge ChatGPT App 与 Claude 目录连接器为只读，仅支持研究和账户查询。如需交易，请使用直接连接 `https://mcp.longbridge.com` 的客户端。

### AI 会不经询问就下单吗？

不会。下单工具默认以预演方式运行并返回预览，只有在你明确确认该笔订单后才会发送。

### 通过 AI 交易会使用真实资金吗？

使用真实账户授权时会 —— 订单均为真实的券商订单。你可以使用模拟账户授权，用模拟资金练习。

### 可以在盘前盘后交易吗？

可以。告诉 AI 允许订单在常规交易时段之外成交即可。美股订单还可以指定夜盘时段，具体取决于标的。

### 需要写代码吗？

不需要。只需连接一次客户端，使用 Longbridge 账户登录，然后用自然语言提问即可。偏好写代码的开发者可以使用 [OpenAPI SDK](/zh-CN/docs) 或 [Longbridge CLI](/zh-CN/docs/cli)。

:::warning 免责声明
本页示例提示词仅供学习参考，不构成投资建议。投资涉及风险，包括可能损失本金。期权交易风险较高，并不适合所有投资者。确认前请务必仔细核对每笔订单的预览。
:::
