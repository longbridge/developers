# longbridge coupon-orders

列出某张卡券（如免佣卡、平台费抵扣卡）所使用的订单。

:::info 仅支持香港（AP）账户
此命令读取 AP（香港）数据中心的数据。美国账户执行时会返回错误，提示该命令在美国数据中心不可用；美国没有对应的命令，重试也不会成功。
:::

## 基本用法

```bash
longbridge coupon-orders --card-id 0123456789abcdef0123456789abcdef
```

## 示例

### 查看使用了某张卡券的订单

```bash
# 卡券 id 为 `longbridge coupons` 中的 card_id（32 位十六进制）
longbridge coupon-orders --card-id 0123456789abcdef0123456789abcdef
longbridge coupon-orders --card-id 0123456789abcdef0123456789abcdef --format json
```

默认表格每个订单一行，显示分组（`locked` 或 `settled`）、订单号、状态、价格、数量、币种、返还金额及返还日期。需要下方列出的全部字段时请使用 `--format json`。

```json
{
  "card_id": "0123456789abcdef0123456789abcdef",
  "locked": [],
  "settled": [
    {
      "order_id": "100000000000000001",
      "state": "Filled",
      "state_val": "FilledStatus",
      "executed_price": "385.20",
      "executed_quantity": "200",
      "currency": "HKD",
      "rebate": "15.00",
      "rebate_dt": "2026-11-04",
      "settlement_currency": "HKD"
    }
  ]
}
```

示例中的值仅作说明。

纯数字的 id 是银行卡 id，不是卡券。请使用 [`coupons`](/zh-CN/docs/cli/account/coupons) 中的 id，而不是 `bank-cards` 中的 id。

## 参数

| 参数 | 说明 |
| --- | --- |
| `--card-id` | 卡券 id（[`coupons`](/zh-CN/docs/cli/account/coupons) 中的 `card_id`）。必填 |

## 输出字段

| 字段 | 说明 |
| --- | --- |
| `card_id` | 查询的卡券 id |
| `locked[]` | 占用该卡、返还尚未结算的订单 |
| `settled[]` | 已结算返还的订单 |

每个订单包含 `order_id`、`state`、`state_val`、`executed_price`、`executed_quantity`、`currency`、`rebate`、`rebate_dt` 和 `settlement_currency`。`rebate_dt` 为返还日期，按服务端返回原样输出，CLI 不做时区转换。输出中不含任何账号。

没有值的字段不会出现在 JSON 中，而不是输出为 `null` 或空字符串。例如返还尚无日期时没有 `rebate_dt`。

## 权限要求

需要 OAuth 账户权限。参见[账户权限设置](/zh-CN/docs/trade/trade-overview)。
