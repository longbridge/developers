# longbridge coupons

列出账户中的卡券——免佣卡、平台费抵扣卡、股票卡、行情 / 基本面卡、现金卡、打新卡等。

:::info 仅支持香港（AP）账户
此命令读取 AP（香港）数据中心的数据，仅支持香港账户。输出中的时间均为香港时间（+08:00）。
:::

## 基本用法

```bash
longbridge coupons
```

## 示例

### 查看未过期卡券

```bash
longbridge coupons
longbridge coupons --format json
```

```json
{
  "cards": [
    {
      "card_id": "3f2a9c0d4b7e4e2f8a1c6d5b9e0f1a2b",
      "card_type": "commission",
      "title": "港股免佣卡",
      "card_status": 0,
      "card_status_label": "unused",
      "start_time": "2026-11-01T00:00:00+08:00",
      "end_time": "2026-12-31T23:59:59+08:00",
      "commission": {
        "markets": ["HK"],
        "targets": ["stocks", "ETF"]
      }
    }
  ],
  "total": 1,
  "expired_count": 3
}
```

### 查看已过期卡券

```bash
longbridge coupons --status expired
```

### 按卡券类型筛选

```bash
# commission、platform_fee_deduct、stock、quote、cash 等
longbridge coupons --card-type platform_fee_deduct
```

### 返回完整使用须知

```bash
longbridge coupons --with-terms
```

默认 `description` 会截短、不返回 `detail`；带 `--with-terms` 时两者都返回全文。

### 翻页

```bash
longbridge coupons --page 2 --size 50
```

App 置顶或置底展示的卡券只在第 1 页返回。

## 参数

| 参数 | 说明 |
| --- | --- |
| `--status` | `valid`（默认，未过期：未使用、使用中或已使用）或 `expired` |
| `--card-type` | 卡券类型，如 `commission`、`platform_fee_deduct`、`stock`、`quote`、`cash`（默认全部） |
| `--with-terms` | 返回每张卡券的完整使用须知（`description`、`detail`） |
| `--page` | 页码（默认 1） |
| `--size` | 每页条数（默认 20，最大 50） |

## 输出字段

`cards[]` 中每项包含：

| 字段 | 说明 |
| --- | --- |
| `card_id` | 卡券 id（32 位十六进制），可传给 [`coupon-orders --card-id`](/zh-CN/docs/cli/account/coupon-orders) |
| `card_type`、`title`、`title_sec`、`description`、`detail` | 卡券类型、标题及使用须知 |
| `card_status`、`card_status_label` | `unused`、`used`、`expired`、`redeeming`、`in_use` 或 `processing` |
| `start_time`、`end_time` | 有效期。永久有效的卡券没有 `end_time`，返回 `no_expiry: true` |
| `activate_time` | 激活时间 |
| `amount`、`currency` | 卡券面值（如适用） |
| `available_trade_session`、`trade_sessions` | 可使用的交易时段 |
| `commission` | `markets`、`targets`（适用标的：`stocks` / `options` / `warrants` / `ETF` / `LOF`）、`rebate_rate`、`bz_types`、`commission_balance`、`commission_expired_time` |
| `quote` | `markets`、`quote_market`、`current_end_time` |
| `stock`、`platform_fee_deduct` 等 | 各类型卡券的专属信息 |

`total` 为符合筛选条件的卡券数，`expired_count` 为已过期卡券数。输出中不含任何账号。

## 权限要求

需要 OAuth 账户权限。参见[账户权限设置](/zh-CN/docs/trade/trade-overview)。
