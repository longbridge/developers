# longbridge stock-transfers-out

列出股票转出申请（股票从你的 Longbridge 账户转到其他券商），按时间倒序。

:::info 仅支持香港（AP）账户
此命令读取 AP（香港）数据中心的数据。美国账户执行时会返回错误，提示该命令在美国数据中心不可用；美国没有对应的命令，重试也不会成功。输出中的时间均为香港时间（+08:00），`--start` / `--end` 传入的日期也按香港日期处理。
:::

## 基本用法

```bash
longbridge stock-transfers-out
```

## 示例

### 查看全部转出申请

```bash
longbridge stock-transfers-out
longbridge stock-transfers-out --format json
```

默认表格先打印总数（如有），再显示 `id`、创建时间、券商（有英文名时显示英文名）、市场、股票（代码及数量，如 `700 x200`）、状态、处理天数、是否已通知券商及原因。需要下方列出的全部字段时请使用 `--format json`。

```json
{
  "records": [
    {
      "id": 1000006,
      "order_id": "TO000000000001",
      "market": "US",
      "broker": "示例证券有限公司",
      "broker_en": "Example Securities Ltd",
      "code": "B00002",
      "account": "****1234",
      "state": "已完成",
      "state_code": 3,
      "state_label": "completed",
      "stocks": [
        {
          "code": "AAPL",
          "name": "苹果",
          "name_en": "Apple Inc.",
          "market": "US",
          "counter_id": "ST/US/AAPL",
          "amount": "50",
          "currency": "USD",
          "state": 1,
          "state_label": "succeeded"
        }
      ],
      "created_at": "2026-09-01T11:02:00+08:00",
      "exec_at": "2026-09-04T16:30:00+08:00",
      "days_in_process": 3
    }
  ],

```

示例中的值仅作说明。

### 按市场和状态筛选

```bash
# 已提交的美股转出（状态 0，唯一仍可撤销的状态）
longbridge stock-transfers-out --market US --state 0
```

### 按创建日期筛选

```bash
longbridge stock-transfers-out --start 2026-09-01 --end 2026-09-30
```

### 翻页

```bash
longbridge stock-transfers-out --page 2 --count 50
```

## 参数

| 参数 | 说明 |
| --- | --- |
| `--market` | `HK`、`US`、`CN` 或 `SG`（默认全部） |
| `--state` | 状态码：`0` 已提交，`1` 处理中，`2` 执行中，`3` 已完成，`4` 已撤销，`5` 部分完成，`6` 失败，`7` 已拒绝（默认全部） |
| `--start`、`--end` | 创建日期范围，`yyyy-mm-dd`（香港日期）或 RFC 3339 |
| `--page` | 页码（默认 1；传 `0` 按 1 处理） |
| `--count` | 每页条数（默认 20，最大 50，超过按 50 处理）。别名：`--size`、`--limit` |

## 输出字段

`records[]` 中每项包含：

| 字段 | 说明 |
| --- | --- |
| `id`、`order_id` | 申请 id 及单号 |
| `market` | 股票所属市场 |
| `broker`、`broker_en`、`code` | 接收券商名称、英文名称及券商代码 |
| `account` | 你在对方券商的账号，**脱敏为仅显示后 4 位** |
| `state`、`state_code`、`state_label` | 状态文案、状态码及标签（`submitted` / `processing` / `executing` / `completed` / `cancelled` / `partially_completed` / `failed` / `rejected`）。仅状态 `0` 仍可撤销 |
| `app_state`、`user_notified_broker` | 同 [`stock-transfers-in`](/zh-CN/docs/cli/account/stock-transfers-in)：只要有 `app_state` 就会有 `user_notified_broker` |
| `stocks[]` | 每只股票的 `code`、`name`、`name_en`、`market`、`counter_id`、`amount`、`currency`、`state`、`state_label`（`processing` / `succeeded` / `failed`） |
| `created_at`、`updated_at`、`agree_at`、`refuse_at`、`cancel_at`、`process_at`、`exec_at` | 各时间点 |
| `days_in_process` | 算法同 [`stock-transfers-in`](/zh-CN/docs/cli/account/stock-transfers-in) |
| `remark`、`reason` | 备注，以及拒绝或撤销原因（如有） |

没有值的字段不会出现在 JSON 中，而不是输出为 `null` 或空字符串。未设置的时间（例如未撤销申请的 `cancel_at`）同样不输出。

`total` 为符合条件的记录数（服务端返回时才有）。账户持有人姓名、联系方式及证明文件不会输出。

## 权限要求

需要 OAuth 账户权限。参见[账户权限设置](/zh-CN/docs/trade/trade-overview)。
