# longbridge edda-status

列出某张绑定银行卡在某个币种下提交过的 eDDA 授权申请。

:::info 仅支持香港（AP）账户
此命令读取 AP（香港）数据中心的数据。美国账户执行时会返回错误，提示该命令在美国数据中心不可用；美国没有对应的命令，重试也不会成功。输出中的时间均为香港时间（+08:00）。
:::

多数 eDDA 授权（例如银行端推送的授权）没有申请单，因此该列表通常为空。要确认某张卡是否已授权，请先使用 [`edda`](/zh-CN/docs/cli/account/edda)；只在需要查申请单时使用本命令。

## 基本用法

```bash
longbridge edda-status --card-id 100001 --currency HKD
```

## 示例

### 查询某张卡的申请

```bash
# 银行卡 id 取自 `longbridge bank-cards`（id）或 `longbridge edda`（card_id）
longbridge edda-status --card-id 100001 --currency HKD
# 同一查询，JSON 输出
longbridge edda-status --card-id 100001 --currency HKD --format json
```

默认表格显示 `id`、授权方式、币种、授权状态、失败原因，以及精确到分钟的创建 / 更新时间。需要下方列出的全部字段时请使用 `--format json`。

```json
{
  "applications": [
    {
      "id": 1000004,
      "flow_id": "hk_sdda",
      "name": "eDDA",
      "currency": "HKD",
      "authorization": "failed",
      "failure_reason": "Account name does not match",
      "created_at": "2026-10-08T14:20:05+08:00",
      "updated_at": "2026-10-09T09:12:40+08:00"
    }
  ]
}
```

示例中的值仅作说明。

列表为空表示该卡在该币种下没有提交过申请，此时该卡当前的 eDDA 状态请看 [`edda`](/zh-CN/docs/cli/account/edda)。

## 参数

| 参数 | 说明 |
| --- | --- |
| `--card-id` | 银行卡 id（数字），取自 [`bank-cards`](/zh-CN/docs/cli/account/bank-cards)。必填 |
| `--currency` | 授权币种，如 `HKD` 或 `USD`。必填 |

## 输出字段

`applications[]` 中每项包含 `id`、`flow_id`、`name`、`currency`、`authorization`（`unauthorized` / `authorized` / `authorizing` / `failed`）、`failure_reason`、`created_at` 和 `updated_at`。输出中不含银行账号。

没有值的字段不会出现在 JSON 中，而不是输出为 `null` 或空字符串。例如申请未失败时没有 `failure_reason`。

## 权限要求

需要 OAuth 账户权限。参见[账户权限设置](/zh-CN/docs/trade/trade-overview)。
