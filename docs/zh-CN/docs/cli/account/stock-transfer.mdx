# longbridge stock-transfer

查看股票转入 / 转出申请（股票在其他券商与你的 Longbridge 账户之间转移）。

:::info 仅支持香港（AP）账户
这些命令读取 AP（香港）数据中心的数据。美国账户执行时会返回错误，提示该命令在美国数据中心不可用；美国没有对应的命令，重试也不会成功。输出中的时间均为香港时间（+08:00），`--start` / `--end` 传入的日期也按香港日期处理。
:::

## 基本用法

```bash
# 股票转入申请（转入 Longbridge）
longbridge stock-transfer in
# 股票转出申请（转到其他券商）
longbridge stock-transfer out
```

## stock-transfer in

列出股票转入申请（股票从其他券商转入你的 Longbridge 账户），按时间倒序。

### 查看全部转入申请

```bash
longbridge stock-transfer in
longbridge stock-transfer in --format json
```

默认表格先打印总数，再显示 `id`、创建时间、券商（有英文名时显示英文名）、市场、股票（代码及数量，如 `700 x200`）、状态、处理天数、是否已通知券商及原因。需要下方列出的全部字段时请使用 `--format json`。

```json
{
  "records": [
    {
      "id": "1000005",
      "order_id": "TI000000000001",
      "market": "HK",
      "broker": "示例证券有限公司",
      "broker_en": "Example Securities Ltd",
      "code": "B00001",
      "account": "****1234",
      "state": "处理中",
      "state_code": 5,
      "state_label": "processing",
      "can_modify": 0,
      "app_state": "noticed",
      "user_notified_broker": true,
      "stocks": [
        {
          "code": "700",
          "name": "腾讯控股",
          "name_en": "Tencent Holdings",
          "market": "HK",
          "counter_id": "ST/HK/700",
          "amount": "200",
          "currency": "HKD",
          "state": 0,
          "state_label": "processing"
        }
      ],
      "created_at": "2026-11-05T10:15:00+08:00",
      "days_in_process": 21
    }
  ],
  "total": 1
}
```

示例中的值仅作说明。

### 按市场和状态筛选

```bash
# 仍在处理中（状态 5）的港股转入
longbridge stock-transfer in --market HK --state 5
```

### 按创建日期筛选

```bash
longbridge stock-transfer in --start 2026-10-01 --end 2026-10-31
```

### 翻页

```bash
longbridge stock-transfer in --page 2 --count 50
```

### 参数

| 参数 | 说明 |
| --- | --- |
| `--market` | `HK`、`US`、`CN` 或 `SG`（默认全部） |
| `--state` | 状态码：`0` 已提交，`1` 已撤销，`3` 已完成（股票已到账），`5` 处理中，`7` 部分完成，`8` 失败（默认全部）。其他状态码会直接报错，不发出请求 |
| `--start`、`--end` | 创建日期范围，`yyyy-mm-dd`（香港日期）或 RFC 3339 |
| `--page` | 页码（默认 1；传 `0` 按 1 处理） |
| `--count` | 每页条数（默认 20，最大 50，超过按 50 处理）。别名：`--size`、`--limit` |

### 输出字段

`records[]` 中每项包含：

| 字段 | 说明 |
| --- | --- |
| `id`、`order_id` | 申请 id 及单号 |
| `market` | 股票所属市场 |
| `broker`、`broker_en`、`code` | 对方券商名称、英文名称及券商代码 |
| `account` | 你在对方券商的账号，**脱敏为仅显示后 4 位** |
| `state`、`state_code`、`state_label` | 状态文案、服务端原始状态码及标签（CLI 未知的状态码没有标签；`submitted` / `cancelled` / `completed` / `processing` / `partially_completed` / `failed`） |
| `can_modify` | 为 `1` 表示仍可在 App 内撤销或修改 |
| `app_state`、`user_notified_broker` | `app_state` 为 App 端的步骤；只要有 `app_state` 就会有 `user_notified_broker`，为 `true` 表示你已在 App 内点击「我已通知」转出券商——这是你自己的确认，不是 Longbridge 的操作 |
| `stocks[]` | 每只股票的 `code`、`name`、`name_en`、`market`、`counter_id`、`amount`、`currency`、`state`（服务端原始状态码）、`state_label`（`processing` / `succeeded` / `failed`） |
| `created_at`、`updated_at`、`process_at`、`exec_at` | 各时间点。转入记录没有 `agree_at`、`refuse_at` 和 `cancel_at` |
| `days_in_process` | 自创建到执行的天数；已结束（已撤销、失败、已完成或部分完成）但没有执行时间的，算到最后更新时间，该时间也未知时不输出；未结束的算到今天 |
| `remark`、`reason` | 失败或撤销原因（如有） |

没有值的字段不会出现在 JSON 中，而不是输出为 `null` 或空字符串。未设置的时间（例如尚未执行时的 `exec_at`）同样不输出。

`total` 为符合条件的记录数。账户持有人姓名、联系方式及证明文件不会输出。

## stock-transfer out

列出股票转出申请（股票从你的 Longbridge 账户转到其他券商），按时间倒序。

### 查看全部转出申请

```bash
longbridge stock-transfer out
longbridge stock-transfer out --format json
```

默认表格显示 `id`、创建时间、券商（有英文名时显示英文名）、市场、股票（代码及数量，如 `700 x200`）、状态、处理天数、是否已通知券商及原因。需要下方列出的全部字段时请使用 `--format json`。

```json
{
  "records": [
    {
      "id": "1000006",
      "order_id": "TO000000000001",
      "market": "US",
      "broker": "示例证券有限公司",
      "broker_en": "Example Securities Ltd",
      "code": "B00002",
      "account": "****1234",
      "state": "已完成",
      "state_code": 3,
      "state_label": "completed",
      "stocks": [
        {
          "code": "AAPL",
          "name": "苹果",
          "name_en": "Apple Inc.",
          "market": "US",
          "counter_id": "ST/US/AAPL",
          "amount": "50",
          "currency": "USD",
          "state": 1,
          "state_label": "succeeded"
        }
      ],
      "created_at": "2026-09-01T11:02:00+08:00",
      "exec_at": "2026-09-04T16:30:00+08:00",
      "days_in_process": 3
    }
  ]
}
```

示例中的值仅作说明。

### 按市场和状态筛选

```bash
# 已提交的美股转出（状态 0，唯一仍可撤销的状态）
longbridge stock-transfer out --market US --state 0
```

### 按创建日期筛选

```bash
longbridge stock-transfer out --start 2026-09-01 --end 2026-09-30
```

### 翻页

```bash
longbridge stock-transfer out --page 2 --count 50
```

### 参数

| 参数 | 说明 |
| --- | --- |
| `--market` | `HK`、`US`、`CN` 或 `SG`（默认全部） |
| `--state` | 状态码：`0` 已提交，`1` 处理中，`2` 执行中，`3` 已完成，`4` 已撤销，`5` 部分完成，`6` 失败，`7` 已拒绝（默认全部）。其他状态码会直接报错，不发出请求 |
| `--start`、`--end` | 创建日期范围，`yyyy-mm-dd`（香港日期）或 RFC 3339 |
| `--page` | 页码（默认 1；传 `0` 按 1 处理） |
| `--count` | 每页条数（默认 20，最大 50，超过按 50 处理）。别名：`--size`、`--limit` |

### 输出字段

`records[]` 中每项包含：

| 字段 | 说明 |
| --- | --- |
| `id`、`order_id` | 申请 id 及单号 |
| `market` | 股票所属市场 |
| `broker`、`broker_en`、`code` | 接收券商名称、英文名称及券商代码 |
| `account` | 你在对方券商的账号，**脱敏为仅显示后 4 位** |
| `state`、`state_code`、`state_label` | 状态文案、服务端原始状态码及标签（CLI 未知的状态码没有标签；`submitted` / `processing` / `executing` / `completed` / `cancelled` / `partially_completed` / `failed` / `rejected`）。仅状态 `0` 仍可撤销 |
| `app_state`、`user_notified_broker` | 同 [`stock-transfer in`](/zh-CN/docs/cli/account/stock-transfer#stock-transfer-in)：只要有 `app_state` 就会有 `user_notified_broker` |
| `stocks[]` | 每只股票的 `code`、`name`、`name_en`、`market`、`counter_id`、`amount`、`currency`、`state`（服务端原始状态码）、`state_label`（`processing` / `succeeded` / `failed`） |
| `created_at`、`updated_at`、`agree_at`、`refuse_at`、`cancel_at`、`process_at`、`exec_at` | 各时间点 |
| `days_in_process` | 自创建到执行的天数；已结束（已撤销、已拒绝、失败、已完成或部分完成）但没有执行时间的，算到 `cancel_at`、`refuse_at` 或最后更新时间，均未知时不输出；未结束的算到今天 |
| `remark`、`reason` | 备注，以及拒绝或撤销原因（如有） |

没有值的字段不会出现在 JSON 中，而不是输出为 `null` 或空字符串。未设置的时间（例如未撤销申请的 `cancel_at`）同样不输出。

转出列表没有 `total`。账户持有人姓名、联系方式及证明文件不会输出。
