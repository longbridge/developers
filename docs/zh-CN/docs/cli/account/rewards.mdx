# longbridge rewards

列出账户获得的活动奖励发放记录——现金、卡券、礼品及任务奖励，按时间倒序。

:::info 仅支持香港（AP）账户
此命令读取 AP（香港）数据中心的数据，仅支持香港账户。输出中的时间均为香港时间（+08:00），`--start` / `--end` 传入的日期也按香港日期处理。
:::

## 基本用法

```bash
longbridge rewards
```

## 示例

### 查看奖励记录

```bash
longbridge rewards
longbridge rewards --format json
```

```json
{
  "rewards": [
    {
      "reward_type": 0,
      "reward_type_label": "cash",
      "record_id": "7300125",
      "activity_title": "新客入金奖励",
      "title": "100 港元现金奖励",
      "amount": "100",
      "currency": "HKD",
      "status": 12,
      "status_label": "issued",
      "send_time": "2026-10-12T09:00:00+08:00"
    }
  ],
  "total": 1
}
```

### 按类型筛选

```bash
# cash、gift、coupon 或 task
longbridge rewards --kind coupon
```

### 按日期范围查找

```bash
longbridge rewards --start 2026-10-01 --end 2026-10-31
```

带 `--start` / `--end` 时，命令按 `send_time` 筛选，并自动翻页读取最多 300 条记录（忽略 `--page`）。此时输出以 `searched_all` 代替 `total`：为 `false` 表示更早的记录未读取，要找的奖励可能在其中。尚未发放（无 `send_time`）的记录总会包含在内。

### 翻页

```bash
longbridge rewards --page 2 --size 50
```

## 参数

| 参数 | 说明 |
| --- | --- |
| `--kind` | `cash`、`gift`、`coupon` 或 `task`（默认全部） |
| `--start`、`--end` | 按 `send_time` 筛选的发放日期范围，`yyyy-mm-dd`（香港日期）或 RFC 3339 |
| `--page` | 页码（默认 1；带 `--start` / `--end` 时忽略） |
| `--size` | 每页条数（默认 20，最大 50） |

## 输出字段

`rewards[]` 中每项包含：

| 字段 | 说明 |
| --- | --- |
| `reward_type`、`reward_type_label` | `cash`、`gift`、`coupon` 或 `task`（与 `--kind` 取值一致） |
| `record_id`、`activity_title`、`title`、`description` | 记录 id、所属活动，以及奖励标题和说明 |
| `card_type`、`card_status` | 卡券类奖励适用 |
| `prize_type`、`prize_type_label` | `physical` 表示寄送的实物 |
| `amount`、`currency` | 奖励金额 |
| `status`、`status_label` | `upcoming`、`cancelled`、`exited_activity`、`unclaimed`、`issuing`、`issued`、`failed`、`exchanged`、`expired` 或 `refunded` |
| `deliver_status`、`deliver_status_label` | 仅已发放的奖品：`not_activated`、`activated_or_shipping`、`consumed`、`address_missing`、`shipping` 等 |
| `send_time`、`start_time`、`end_time`、`effective_time`、`receive_deadline` | 各时间点；未设置的占位值不输出 |

`total` 为所选类型的全部记录数（仅不带 `--start` / `--end` 时返回）。一笔奖励由 `activity_title` 和 `send_time` 确定；奖励发放的卡券用 [`coupons`](/zh-CN/docs/cli/account/coupons) 查看。兑换码、券密、收货地址及电话不会输出。

## 权限要求

需要 OAuth 账户权限。参见[账户权限设置](/zh-CN/docs/trade/trade-overview)。
