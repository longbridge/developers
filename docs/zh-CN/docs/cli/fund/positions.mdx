# longbridge fund（持仓）

查看你的基金持仓——持仓总览、单只持仓详情,及其业绩、累计收益、净值历史与分红。

基金以其 **`counter_id`**（如 `UT/FD/HK0000384492`）标识。这些命令读取你的账户,需要登录。

## 基本用法

```bash
# 你持有的每只基金总览
longbridge fund positions
```

```
| Counter ID          | Name                        | Currency | Holding Units | Cost NAV | Current NAV | Holding Profit |
|---------------------|-----------------------------|----------|---------------|----------|-------------|----------------|
| UT/FD/HK0000384492  | Allianz Income and Growth   | USD      | 1250.00       | 9.812    | 10.431      | +773.75        |
```

## 示例

### 持仓总览

```bash
longbridge fund positions
# 限定到某个子账户
longbridge fund positions --account-channel lb --aaid 123456
```

### 单只持仓

```bash
# 单只持有基金的详情,可选日期区间
longbridge fund position UT/FD/HK0000384492
longbridge fund position UT/FD/HK0000384492 --start 2026-01-01 --end 2026-06-30
```

### 持有基金的业绩、收益、净值与分红

```bash
# 持有基金的业绩数据
longbridge fund position-performance UT/FD/HK0000384492
# 累计收益序列(分页、日期区间)
longbridge fund position-profits UT/FD/HK0000384492 --start 2026-01-01 --end 2026-06-30 --page 1 --size 30
# 相对时间窗内的净值历史
longbridge fund position-nav UT/FD/HK0000384492 --month-before 6
longbridge fund position-nav UT/FD/HK0000384492 --year-before 1
# 分红记录
longbridge fund position-dividends UT/FD/HK0000384492 --currency USD --page 1 --size 20
```

任意命令加 `--format json` 可输出机器可读格式。

## 选项

| 选项 | 命令 | 说明 | 默认 |
| ---- | ---- | ---- | ---- |
| `--account-channel` | `positions`、`position` | 账户渠道 | — |
| `--aaid` | `positions`、`position` | 子账户 id | — |
| `--start` / `--end` | `position`、`position-profits`、`position-dividends` | 日期区间(`YYYY-MM-DD` 或 RFC 3339) | — |
| `--month-before` / `--year-before` | `position-nav` | 相对当前的净值时间窗 | — |
| `--currency` | `position-dividends` | 币种筛选(如 `HKD`、`USD`) | — |
| `--page` / `--size` | `position-profits`、`position-dividends` | 页码与每页条数 | — |
| `--format` | 全部 | 输出格式:`table` \| `json` | `table` |

## 要求

需要 OAuth 账户权限——先运行 `longbridge auth login`。基金以 `counter_id` 寻址(来自 [`fund hot` / `fund list`](/zh-CN/docs/cli/fund/market))。下单或撤单见 [订单与交易](/zh-CN/docs/cli/fund/orders)。
