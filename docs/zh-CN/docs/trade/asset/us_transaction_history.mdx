分页获取美股账户的交易流水，包括存取款、交易、公司行动、转仓、融资等。

<SDKLinks module="trade" klass="TradeContext" method="us_transaction_history" />

</tbody>

## Parameters

> Content-Type: application/json; charset=utf-8
>
> SDK 方法使用 `start_at` 和 `end_at`（日期时间类型）代替 `start` 和 `end`，其余参数同名。

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| start | integer | 是 | 开始时间（Unix 秒），包含 |
| end | integer | 是 | 结束时间（Unix 秒），包含 |
| page | integer | 否 | 页码，从 `1` 开始（默认：`1`） |
| size | integer | 否 | 每页数量（默认：`20`） |
| types | string[] | 否 | 要查询的流水类型，不传则返回全部类型，见[流水类型](#transaction-types) |
| currency | string | 否 | 按币种筛选，例如 `USD`，不传则返回全部币种 |

### 流水类型

<a id="transaction-types"></a>

| 取值 | 描述 |
| ---- | ---- |
| `TT_DEPOSIT_AND_WITHDRAWAL` | 存取款 |
| `TT_STOCKS_AND_ETFS_TRADING` | 股票和 ETF 交易 |
| `TT_OPTIONS_TRADING` | 期权交易 |
| `TT_CRYPTO_TRADING` | 加密货币交易 |
| `TT_CORPORATE_ACTION` | 公司行动 |
| `TT_TRANSFER_IN_AND_OUT` | 转入转出 |
| `TT_CRYPTO_TRANSFER` | 加密货币转账 |
| `TT_MARGIN_FINANCING` | 融资 |
| `TT_OTHER` | 其他 |

## Response

响应不返回总条数。当某页返回的记录数少于 `size` 时，即为最后一页。

HTTP 接口中，`create_at` 和 `done_at` 是以数字字符串表示的 Unix 秒（例如 `"1790203596"`），SDK 会将其转换为日期时间类型。

## Schemas

### USTransactionHistory

<a id="USTransactionHistory"></a>

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| current_page | integer | 是 | 当前页码 |
| items | [USTransaction](#USTransaction)[] | 是 | 本页记录 |

### USTransaction

<a id="USTransaction"></a>

| 名称 | 类型 | 描述 |
| ---- | ---- | ---- |
| title | string | 展示标题，例如 `VA Sell Success: ETHUSD` |
| biz_code | string | 业务代码，例如 `LVASAD`，参见[业务代码](#biz-codes) |
| biz_code_name | string | 业务代码的展示名称，例如 `VA Sell Success` |
| amount | string | 金额 |
| currency | string | 货币，例如 `USD`；可能为空，例如加密货币转入 |
| symbol | string | `TICKER.MARKET` 格式的标的代码，例如 `MULL.US` 或 `BTCUSD.BKKT`（仅当记录与证券相关时返回） |
| counter_id | string | 与 `symbol` 一同返回的内部标的标识，例如 `VA/BKKT/BTCUSD`。由 HTTP 接口返回，SDK 类型中可能未包含 |
| market | string | 市场，例如 `US` 或 `BKKT` |
| equity_type | string | 持仓类型，例如 `STOCK`、`OPTION`、`CRYPTO` |
| position_side | string | 持仓方向：`LONG` \| `SHORT` |
| quantity | string | 数量 |
| quantity_description | string | 数量描述 |
| ref_no | string | 参考编号 |
| remark | string | 备注 |
| create_at | string | 创建时间，以数字字符串表示的 Unix 秒；SDK 返回日期时间类型 |
| done_at | string | 完成时间，以数字字符串表示的 Unix 秒；SDK 返回日期时间类型 |

### 业务代码

<a id="biz-codes"></a>

`biz_code` 标识记录的类型。生产环境中出现过的取值包括：

| biz_code | 描述 |
| -------- | ---- |
| `LVABAD` | 加密货币买入成交（`biz_code_name`：`VA Buy Success`） |
| `LVASAD` | 加密货币卖出成交（`biz_code_name`：`VA Sell Success`） |
| `LVAVNSCR` | 加密货币转入（`biz_code_name`：`Cryptocurrency Deposit`） |
| `LCSTBD` | 生产环境中出现过，展示名称以 `biz_code_name` 为准 |
| `LCWD` | 生产环境中出现过，展示名称以 `biz_code_name` 为准 |

以上列表并不完整，可能出现其他取值。`title` 和 `biz_code_name` 为展示文本，语言可能不同，程序逻辑请使用 `biz_code` 判断。
