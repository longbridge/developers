## Response

HTTP 接口以两级映射返回汇率：

- `universal_exchanges` 的外层键为账户通道，例如 `us_lb_apex`。
- `spec_exchanges` 的内层键为汇率类型，例如 `am` 或 `reference`。

可能出现其他键，请遍历映射读取，不要写死键名。HTTP 接口中汇率字段为 JSON 数字。

SDK 会将该映射展开为单个 `exchanges` 列表，每条记录除汇率字段外，还以 `universal_key` 和 `spec_key` 保留两层键，汇率以字符串返回。

## Schemas

### USExchangeRates

<a id="USExchangeRates"></a>

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| universal_exchanges | map&lt;string, [USUniversalExchanges](#USUniversalExchanges)&gt; | 是 | 以账户通道为键的汇率，例如 `us_lb_apex` |

### USUniversalExchanges

<a id="USUniversalExchanges"></a>

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| spec_exchanges | map&lt;string, [USSpecExchanges](#USSpecExchanges)&gt; | 是 | 以汇率类型为键的汇率，例如 `am` 或 `reference` |

### USSpecExchanges

<a id="USSpecExchanges"></a>

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| exchanges | [USExchangeRate](#USExchangeRate)[] | 是 | 该汇率类型下的汇率 |

### USExchangeRate

<a id="USExchangeRate"></a>

| 名称 | 类型 | 描述 |
| ---- | ---- | ---- |
| base_currency | string | 基础货币 |
| other_currency | string | 报价货币 |
| bid_rate | number | 买入汇率。SDK 以字符串返回 |
| offer_rate | number | 卖出汇率。SDK 以字符串返回 |
| average_rate | number | 平均汇率。SDK 以字符串返回 |

SDK 返回的每条 `exchanges` 记录还包含：

| 名称 | 类型 | 描述 |
| ---- | ---- | ---- |
| universal_key | string | 该汇率所属的账户通道（`universal_exchanges` 的键），例如 `us_lb_apex` |
| spec_key | string | 该汇率的类型（`spec_exchanges` 的键），例如 `am` 或 `reference` |
