# 外匯兌換接口總覽

外匯兌換渠道用於將一種貨幣的餘額兌換為另一種貨幣。兌換是異步的，分為三個步驟：

1. **獲取報價** — 調用[獲取報價](./quote)鎖定執行匯率並獲得 `quote_id`。報價與您綁定，並在一個較短的時間窗口後過期。
2. **提交兌換訂單** — 使用該 `quote_id` 和您自己的 `client_order_id` 調用[提交兌換訂單](./submit)發起兌換。是否受理會同步返回，但兌換本身為異步處理。
3. **查詢兌換訂單** — 使用相同的 `client_order_id` 輪詢[查詢兌換訂單](./query)，直到訂單到達終態（成功或失敗）。
