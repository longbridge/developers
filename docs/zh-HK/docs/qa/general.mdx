## Q1: 一定要開通真實帳號才能呼叫 Longbridge Developers 嗎？

取決於帳戶所屬地區。對於 Longbridge 香港 / 新加坡帳戶，平台提供**模擬帳戶**，無需開通真實證券帳戶即可完成行情與交易介面的開發偵錯。**模擬帳戶**支援港股、美股、A 股即時行情查詢，以及港美股股票、ETF 等基礎交易功能，適合介面聯調與功能驗證。

不過，模擬帳戶在交易撮合、資金規則等方面與真實環境存在差異，如需完整體驗平台能力，建議同時開通真實帳戶。

## Q2: 如何開通模擬帳戶調試？

請造訪 [開發者中心](https://open.longbridge.com/dashboard/) 開啟**模擬帳號**並取得模擬帳號對應的 App Key & Secret 以及 Access Token 等資訊。

如需在模擬帳戶上測試，請使用該模擬帳戶自己的 Access Token 或 OAuth 授權調用接口，請求進入模擬帳戶還是實盤帳戶由所用憑證決定。

SDK 另外提供一個模擬盤開關（環境變數 `LONGBRIDGE_PAPERTRADING=true`，或建立 `Config` 時設定 `enable_papertrading`）。開啟後，每個請求都會帶上 `x-papertrading: true` 請求標頭，要求伺服器按模擬帳戶處理，並在憑證屬於實盤帳戶時拒絕請求。

:::warning
這是**伺服器端校驗，不是用戶端保證**，目前有兩處限制，且在回應中看不出來：

- **美國（LBUS）帳戶沒有模擬盤環境**，不存在可供服務的模擬帳戶。伺服器不會拒絕請求，而是直接返回**實盤帳戶**的資料——下單和查詢都是如此，回應裡沒有任何跡象表明這個開關被忽略了。該本地攔截自包含此修復的 SDK 版本起生效，5.5.0 尚未包含。
- **使用 OAuth 授權時，伺服器目前不做這項校驗**（任何地區）：實盤 Token 會被正常接受，查詢類接口返回實盤資料且不報錯。香港 / 新加坡實盤帳戶實測確認：開啟開關後查詢持倉，返回的仍是同一份實盤持倉，沒有任何報錯。

請不要把這個開關當作隔離實盤資金的唯一手段。真正決定請求進入哪個帳戶的是你授權時用的憑證，交易前請先確認這一點；另外要注意，讀回來的持倉、訂單、資金也都是實盤帳戶的，所以即使只做查詢，策略拿到的也已經是實盤資料。
:::

## Q3: 模擬偵錯的行情交易權限與真實帳戶相同嗎？

行情相同，交易不同。

模擬帳號和真實帳號共用 App Key & Secret，不同 Access Token。其中，行情權限與 App Key & Secret 關聯，交易權限與 Access Token 關聯，因此模擬帳戶和真實帳戶下，行情權限相同，交易權限與證券帳號關聯，可能會不同。

## Q4: 模擬調試支援哪些市場和品種的行情和交易

模擬帳戶僅面向 Longbridge 香港 / 新加坡帳戶提供。

行情：模擬帳戶支援港股、美股、A 股通市場即時行情，其中，美股全美行情、港股 Level2 等高級行情也可透過線上行情商店購買對應行情權益後，透過 OpenAPI 取得行情資料。

交易：模擬帳戶支援港美股股票、ETF、港股輪證、美股期權交易。

實盤帳戶中，港股、A 股和港股輪證面向 Longbridge 香港 / 新加坡帳戶提供。

## Q5: 介面呼叫頻次及數量限制

請造訪 [頻率限制](/docs/#rate-limit) 查看具體描述。

## Q6: 多個帳戶情況下，介面呼叫頻次如何限制

若客戶持有多個證券帳戶，例如日內融或其他子帳戶，交易介面呼叫頻次及數量限制依不同的證券帳戶統計及控制，行情介面則不受多帳戶影響，統一限制。

## Q7: 透過 Longbridge Developers 進行交易操作有額外收費嗎

透過 OpenAPI 存取進行行情查詢、交易等，我們不會收取額外的費用。交易手續費、平台費、行情權限等帳戶相關的費用，請以 App 以及官網提供的資訊為準。

## Q8: 如何關閉 SDK 連接到伺服器後的控制台下的權限表輸出

您可以設置環境變數 `LONGBRIDGE_PRINT_QUOTE_PACKAGES` 為 `false`（或舊版 `LONGPORT_PRINT_QUOTE_PACKAGES`），或在代碼中創建 `Config` 對象時設置 `enable_print_quote_packages` 為 `false`，來關閉控制台下的權限表輸出。

## Q9: 我不會寫程式，如何才能存取 Longbridge Developers 平台的個股數據？

平台提供兩種無需寫程式即可存取個股數據的方式：

**CLI（命令列工具）**

安裝 [Longbridge CLI](/docs/cli)，透過簡單指令即可查詢行情數據，無需撰寫任何程式碼：

```bash
longbridge quote AAPL.US TSLA.US
longbridge static NVDA.US
```

**MCP（AI 工具整合）**

如果你日常使用 ChatGPT、Claude、Cursor 等 AI 工具，可以透過 [Longbridge MCP 服務](/zh-HK/docs/mcp)接入。ChatGPT 可在 Plugins 中搜尋 `longbridge` 或直接打開 [Longbridge ChatGPT App](https://chatgpt.com/plugins/longbridge) 完成授權；其他客戶端設定完成後，也可以直接用自然語言向 AI 提問，由 AI 代你呼叫行情介面取得數據。

兩種方式均需擁有 Longbridge 帳戶。
