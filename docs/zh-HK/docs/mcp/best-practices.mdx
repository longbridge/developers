# 安全最佳實踐

## 安全建議

- **最小權限**：授權時僅同意當前任務所需的 scope，避免過度授權
- **交易確認**：所有落盤類工具都會先以試運行（dry run）方式執行，須經你明確確認後才會送出（見[落盤確認機制](/zh-HK/docs/mcp/trading#落盤確認機制)）；仍建議在 AI 提示詞中明確要求執行前人工確認
- **憑證安全**：OAuth 憑證由客戶端管理，避免將其複製至不受信任的環境
- **定期審查**：定期在 [Longbridge 帳戶](https://longbridge.com/hk/download)安全設定中檢查並撤銷不再使用的授權

## 推薦使用方式

1. **從唯讀能力開始**：優先使用[行情查詢](https://longbridge.com/markets)、帳戶概覽、持倉查看等低風險功能，熟悉工具行為
2. **先用模擬帳戶練習**：使用模擬帳戶授權，在不動用真實資金的情況下演練落盤流程
3. **逐步開放交易能力**：確認權限範圍和風控邏輯後，再使用下單相關工具
4. **在提示詞中加入限制**：例如「每筆交易金額不超過 X」、「執行前向我確認」等明確限制
