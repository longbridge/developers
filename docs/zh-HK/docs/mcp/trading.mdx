# 用 AI 交易股票和期權

將 Claude Code、Codex、Cursor 或其他 MCP 客戶端連接到你的 Longbridge 帳戶後，即可用自然語言研究市場、查看投資組合、分析期權鏈，並為美股、港股、ETF、期權和基金落盤。

本指南介紹從接入客戶端到完成第一筆落盤的完整流程。

## AI 可以透過 Longbridge 交易股票嗎？

可以。Longbridge MCP 會將自然語言指令轉換為真實的券商訂單。在準備交易前，AI 可以查詢你的購買力、持倉、即時報價和未成交訂單。支援的訂單功能包括：

- **訂單類型**：限價單和市價單、觸價限價單 / 觸價市價單，以及按金額或百分比設定的跟蹤止損單。港股另支援增強限價單、競價單和碎股單
- **交易時段**：常規交易時段、美股盤前及盤後，以及美股夜盤
- **止盈止損**：可為訂單附加止盈、止損，或同時附加兩者（括號單）
- **訂單管理**：修改未成交訂單的價格或數量（改單），或撤銷訂單（撤單）
- **有效期**：當日有效、撤單前有效及指定日期前有效

每筆訂單都需經過[兩步確認](#落盤確認機制) —— 在你確認具體訂單內容前，任何訂單都不會送至交易所。

## AI 可以用你的 Longbridge 帳戶做什麼？

授權後，AI 可以代你使用 [190+ 工具](/zh-HK/docs/mcp/tools)，包括：

- 美股、港股及 A 股的即時報價、K 線、盤口深度和資金流向
- 帳戶餘額、持倉、盈虧分析、訂單、成交記錄及結單
- 基本面、估值、分析師評級、新聞及公告
- 期權鏈、含引伸波幅及希臘值的期權報價，以及認沽 / 認購成交量
- 附帶止盈 / 止損的股票訂單
- 以單一訂單提交的期權多腿組合策略
- 基金訂單、定投（DCA）計劃、網格交易及股價提醒

存取範圍僅限於你帳戶已開通的市場、產品和權限，以及你授予的 OAuth 授權範圍。

## 將 AI 客戶端連接到 Longbridge

你需要：

- 已完成開戶的 [Longbridge 帳戶](https://longbridge.com/hk/download)，或模擬帳戶
- 支援交易的 MCP 客戶端 —— Claude Code、Codex、Cursor、Zed，或其他直接連接 `https://mcp.longbridge.com` 的客戶端

:::warning ChatGPT 與 Claude 連接器為唯讀
Longbridge ChatGPT App 與 Claude 應用目錄連接器不含交易工具。可用於研究和帳戶查詢；如需落盤，請使用直接連接的客戶端。
:::

### 第一步：添加 Longbridge MCP 服務

以 Claude Code 為例：

```bash
claude mcp add --transport http longbridge https://mcp.longbridge.com
```

其他客戶端請參閱[客戶端接入](/zh-HK/docs/mcp/setup)。

### 第二步：使用 Longbridge 帳戶授權

在 Claude Code 中輸入 `/mcp`，選擇 `longbridge`，再選擇 **Authenticate**。瀏覽器會開啟 Longbridge 登入頁面 —— 登入並同意所請求的權限即可。整個過程無需在對話中貼上任何 API 金鑰或 Token。詳見[授權](/zh-HK/docs/mcp/authorization)。

### 第三步：驗證連接

向 AI 提出一個需要讀取帳戶的問題：

```text
顯示我的 Longbridge 帳戶餘額和購買力。
```

如果返回了你的現金和購買力，即表示已連接成功。

## 研究市場與投資組合

AI 將對話與即時行情及帳戶數據結合，你可以連續追問，無需切換 App。

```text
顯示我目前的持倉、今日盈虧，以及哪隻股票變動最大。
```

```text
比較 NVDA.US、AMD.US 和 700.HK 的現價、市盈率及今日表現。
```

```text
總結 TSLA.US 的最新新聞和分析師評級變動。
```

AI 亦可查詢你的未成交訂單、歷史訂單、成交記錄、資金流水及月結單。

## 交易股票和 ETF

描述你想下的訂單，AI 會準備好訂單並先向你展示預覽，然後才會送出。

```text
以 200 美元限價買入 10 股 AAPL.US，當日有效。
```

```text
以市價買入 100 股 QQQ.US，止盈價 560 美元，止損價 480 美元。
```

```text
顯示我的未成交訂單，並撤銷 TSLA.US 的限價單。
```

如需在延長時段交易，請明確提出：

```text
準備一張以 170 美元限價買入 5 股 NVDA.US 的訂單，允許在盤前及盤後成交。送出前先給我看訂單詳情。
```

不確定能買多少？可以先問：

```text
以我目前的購買力，按 420 美元計可以買多少股 MSFT.US？
```

## 落盤確認機制

所有落盤、改單或撤單工具預設都以**試運行（dry run）**方式執行：

1. AI 調用下單工具但不實際執行。Longbridge 會校驗訂單並返回預覽及一個三位數的**確認碼** —— 訂單不會送至交易所。
2. AI 向你展示預覽：股票代碼、買賣方向、數量、價格、訂單類型及交易時段。
3. 只有在你明確確認後，AI 才會攜帶確認碼再次調用工具，訂單隨即送出。

確認碼僅可使用一次，10 分鐘內有效，並與該筆訂單綁定 —— 任何欄位有變動都需要重新預覽。這可防止誤下訂單或因誤解指令而落盤。

## 交易期權與分析期權鏈

AI 可以瀏覽到期日和行使價，並為你關注的合約拉取含引伸波幅及希臘值的報價。

```text
顯示 AAPL.US 下週五到期的期權鏈，只看認購期權，行使價在現價上下 5% 以內。
```

```text
顯示 AAPL.US 下週五到期、行使價 250 美元認購期權的 Delta、Gamma、Theta 及引伸波幅。
```

```text
NVDA.US 今日的認沽 / 認購成交量比率是多少？哪些合約最活躍？
```

準備好後，單腿期權訂單與股票訂單一樣，遵循先預覽後確認的流程。

## 構建期權多腿組合策略

Longbridge 原生支援多腿訂單，策略的所有腿會作為一張訂單提交，並以單一淨價格同時成交。支援的策略包括：

- 認購及認沽垂直價差
- 跨式及勒式
- 認購及認沽日曆價差
- 備兌認購、備兌認沽及領口策略

```text
為 SPY.US 構建一個兩週後到期的牛市認購價差：買入行使價 580 美元的認購期權，賣出行使價 590 美元的認購期權。落盤前先給我看各條腿、淨支出及最大盈利和虧損。
```

可用策略取決於你帳戶的期權交易等級。

## 股票和期權以外

同一連接亦支援：

- **基金**：瀏覽基金、查看業績及持倉，並提交基金認購或贖回訂單
- **定投計劃**：建立、暫停、恢復或更新定期定額投資
- **網格交易**：設定在價格區間內自動買賣的網格訂單
- **股價提醒**：當股價突破某價位或漲跌達到某百分比時通知你

```text
建立一個每月定投計劃，每月 1 號投資 500 美元買入 VOO.US。
```

```text
當 NVDA.US 跌穿 160 美元時提醒我。
```

## 用模擬帳戶練習

還未準備好用真金白銀交易？使用模擬帳戶授權 Longbridge MCP，即可用模擬資金演練整個流程 —— 研究、構建訂單、確認及撤單。使用真實帳戶授權時，訂單均為真實的券商訂單。

## 為什麼將 AI 連接到 Longbridge？

- **在同一對話中由研究到執行**：行情數據、基本面、組合情況、構建訂單、預覽及執行，無需切換 App
- **多市場覆蓋**：一個帳戶即可交易美股、港股、ETF、期權、窩輪及基金
- **內建安全保障**：每筆訂單都需你明確確認具體內容，並由你控制 AI 獲得的權限
- **無需 API 金鑰**：標準 OAuth 2.1 登入，可隨時在帳戶安全設定中撤銷

## 常見問題

### AI 可以用 Longbridge 交易股票嗎？

可以。直接連接 Longbridge MCP 服務的客戶端 —— 例如 Claude Code、Codex 和 Cursor —— 可以為美股和港股的股票及 ETF 落盤、改單和撤單。

### AI 可以用 Longbridge 交易期權嗎？

可以，包括單腿訂單及多腿組合策略，視乎你帳戶的期權交易等級。

### 可以在 ChatGPT 或 Claude App 中交易嗎？

暫時不可以。Longbridge ChatGPT App 與 Claude 應用目錄連接器為唯讀，僅支援研究和帳戶查詢。如需交易，請使用直接連接 `https://mcp.longbridge.com` 的客戶端。

### AI 會在未經我同意的情況下落盤嗎？

不會。下單工具預設以試運行方式執行並返回預覽，只有在你明確確認該筆訂單後才會送出。

### 透過 AI 交易會使用真實資金嗎？

使用真實帳戶授權時會 —— 訂單均為真實的券商訂單。你可以使用模擬帳戶授權，用模擬資金練習。

### 可以在盤前及盤後交易嗎？

可以。請要求 AI 允許訂單在常規交易時段以外成交。視乎證券而定，美股訂單亦可在夜盤交易。

### 需要寫程式碼嗎？

不需要。只需接入客戶端一次，用 Longbridge 帳戶登入，再用自然語言提問即可。偏好寫程式碼的開發者可以使用 [OpenAPI SDK](/zh-HK/docs) 或 [Longbridge CLI](/zh-HK/docs/cli)。
