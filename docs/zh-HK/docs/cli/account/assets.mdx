# longbridge assets

查看完整帳戶概覽——淨資產、購買力、保證金狀態、風險等級，以及各幣種的現金餘額。

:::info Longbridge US 賬戶
在美股數據中心賬戶上，`assets` 讀取 [美股現金與購買力](/zh-HK/docs/trade/asset/us_cash_and_buy_power) 接口，`--format json` 輸出的欄位與 AP 賬戶一致：一個元素對應賬戶幣種，包含 `currency`、`net_assets`、`total_cash`、`buy_power`、`maintenance_margin` 和 `cash_infos`。沒有美股數據來源的 AP 專屬欄位會省略（賬戶未返回淨清算價值時沒有 `net_assets`），購買力與保證金明細位於 `us` 下。運行 `longbridge assets --schema` 可查看哪些欄位標註為 `(US only)`。
:::

longbridge assets

## 示例

### 查看帳戶概覽

```bash
longbridge assets
longbridge assets --format json
```

以表格形式展示淨資產、總現金、購買力、保證金使用情況及風險等級。

## 權限要求

需要 OAuth 帳戶權限。參見[帳戶權限設置](/zh-HK/docs/trade/)。
