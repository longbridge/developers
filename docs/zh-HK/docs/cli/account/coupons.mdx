# longbridge coupons

列出賬戶中的卡券：免佣卡、平台費抵扣卡、股票卡、行情 / 基本面數據卡、現金卡、IPO 卡等。

:::info 僅支持香港（AP）賬戶
此命令讀取 AP（香港）數據中心的數據。美國賬戶執行時會返回錯誤，提示該命令在美國數據中心不可用；美國沒有對應的命令，重試也不會成功。輸出中的時間均為香港時間（+08:00）。
:::

## 基本用法

```bash
longbridge coupons
```

## 示例

### 查看有效卡券

```bash
longbridge coupons
longbridge coupons --format json
```

預設表格顯示卡券 id、類型、標題、金額（有面值時含幣種）、狀態、生效時間及到期時間（永久有效顯示 `no expiry`），最後打印總數及已過期數。需要下方列出的全部字段時請使用 `--format json`。

```json
{
  "cards": [
    {
      "card_id": "0123456789abcdef0123456789abcdef",
      "card_type": "commission",
      "title": "港股免佣卡",
      "card_status": 0,
      "card_status_label": "unused",
      "start_time": "2026-11-01T00:00:00+08:00",
      "end_time": "2026-12-31T23:59:59+08:00",
      "commission": {
        "markets": ["HK"],
        "bz_types": [0, 3],
        "targets": ["stocks", "ETF"]
      }
    }
  ],
  "total": 1,
  "expired_count": 3
}
```

示例中的值僅作說明。

### 查看已過期卡券

```bash
longbridge coupons --status expired
```

### 按卡券類型篩選

```bash
# commission、platform_fee_deduct、stock、quote、cash 等
longbridge coupons --card-type platform_fee_deduct
```

### 包含完整使用須知

```bash
longbridge coupons --with-terms
```

預設 `description` 會被截短，`detail` 不輸出；`--with-terms` 會完整返回兩者。

### 翻頁

```bash
longbridge coupons --page 2 --count 50
```

App 置頂或置底展示的卡券只在第 1 頁返回。

## 參數

| 參數 | 說明 |
| --- | --- |
| `--status` | `valid`（預設，未過期：未使用、使用中或已使用）或 `expired` |
| `--card-type` | 卡券類型，如 `commission`、`platform_fee_deduct`、`stock`、`quote`、`cash`（預設全部） |
| `--with-terms` | 返回每張卡券完整的使用須知（`description`、`detail`） |
| `--page` | 頁碼（預設 1；傳 `0` 按 1 處理） |
| `--count` | 每頁條數（預設 20，最大 50，超過按 50 處理）。別名：`--size`、`--limit` |

## 輸出字段

`cards[]` 中每項包含：

| 字段 | 說明 |
| --- | --- |
| `card_id` | 卡券 id（32 位十六進制），可傳給 [`coupon-orders --card-id`](/zh-HK/docs/cli/account/coupon-orders) |
| `card_type`、`title`、`title_sec`、`description`、`detail` | 卡券類型、標題及使用須知 |
| `card_status`、`card_status_label` | `unused`、`used`、`expired`、`redeeming`、`in_use` 或 `processing` |
| `start_time`、`end_time` | 有效期。永久有效的卡券沒有 `end_time`，返回 `no_expiry: true` |
| `activate_time` | 激活時間 |
| `amount`、`currency` | 卡券面值（如適用） |
| `available_trade_session`、`trade_sessions` | 可使用的交易時段 |
| `commission` | `markets`、`bz_types`（適用標的類型碼）、`targets`（同一組類型碼的名稱：`stocks` / `options` / `warrants` / `ETF` / `LOF`，只要有 `bz_types` 就會有）、`rebate_rate`、`commission_balance`、`commission_expired_time` |
| `quote` | `markets`、`quote_market`、`current_end_time` |
| `stock`、`platform_fee_deduct` 等 | 各類型卡券的專屬信息 |

沒有值的字段不會出現在 JSON 中，而不是輸出為 `null` 或空字符串。例如從未激活的卡券沒有 `activate_time`。

`total` 為符合篩選條件的卡券數，`expired_count` 為已過期卡券數。輸出中不含任何賬號。

## 權限要求

需要 OAuth 賬戶權限。參見[賬戶權限設置](/zh-HK/docs/trade/trade-overview)。
