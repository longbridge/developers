# longbridge bank-cards

查看綁定至 Longbridge 賬戶的銀行卡列表，包括每張卡的審核狀態及其授權（eDDA、銀證轉賬、FPS）。

:::info 僅支持香港（AP）賬戶
此命令讀取 AP（香港）數據中心的數據，僅支持香港賬戶。輸出中的時間均為香港時間（+08:00）。
:::

## 基本用法

```bash
longbridge bank-cards
```

## 示例

### 查看綁定銀行卡

```bash
longbridge bank-cards
# JSON 輸出，適合腳本使用
longbridge bank-cards --format json
```

## 輸出字段

`cards[]` 中每項包含：

| 字段 | 說明 |
| --- | --- |
| `id` | 銀行卡 id，可傳給 [`edda-status --card-id`](/zh-HK/docs/cli/account/edda-status) |
| `bank`、`bank_en`、`bank_code` | 銀行名稱、英文名稱及銀行代碼 |
| `account` | 銀行賬號，**脫敏為僅顯示後 4 位**（如 `****9779`） |
| `account_type`、`region`、`region_name`、`country` | 賬戶類型及銀行賬戶所在地（`country` 是地區，不是貨幣） |
| `verification` | `unverified`（尚未認證：用這張卡入金任意金額，或完成 eDDA / 銀證轉賬授權即可認證）、`under_review`（綁卡後人工審核中，期間不能使用）或 `verified`（已認證） |
| `witness` | `not_required`、`pending` 或 `witnessed` |
| `binding` | `binding`、`bound` 或 `failed` |
| `review_days` | 卡片添加至今的天數，僅 `under_review` 時返回 |
| `bind_tip`、`remark` | App 中展示的審核提示及備註 |
| `created_at` | 添加時間 |
| `auth_list[]` | 該卡的授權：`flow_id`（`hk_edda` / `hk_sdda`：eDDA，`hk_bank_sec`：銀證轉賬，`hk_fps`：FPS）、`name`、`currency`、`authorization`（`unauthorized` / `authorized` / `authorizing` / `failed`）、`failure_reason`、`max_amount`、`max_amount_unlimited`、`daily_max_count`、`daily_max_count_unlimited`、`expiry_date`、`long_term_valid`、`is_support`、`doc_reviewing`、`no_prior_deposit_reviewing` |

只返回上述字段，完整賬號、身份證明文件圖片及收款人地址不會輸出。只查看 eDDA 授權可使用 [`edda`](/zh-HK/docs/cli/account/edda)。

## 權限要求

需要 OAuth 賬戶權限。參見[賬戶權限設置](/zh-HK/docs/trade/trade-overview)。
