# longbridge stock-transfers-in

列出股票轉入申請（從其他券商轉入 Longbridge 賬戶），按時間倒序。

:::info 僅支持香港（AP）賬戶
此命令讀取 AP（香港）數據中心的數據，僅支持香港賬戶。輸出中的時間均為香港時間（+08:00），`--start` / `--end` 傳入的日期也按香港日期處理。
:::

## 基本用法

```bash
longbridge stock-transfers-in
```

## 示例

### 查看全部轉入申請

```bash
longbridge stock-transfers-in
longbridge stock-transfers-in --format json
```

```json
{
  "records": [
    {
      "id": 51234,
      "order_id": "TI202611050001",
      "market": "HK",
      "broker": "富途證券",
      "code": "B01234",
      "account": "****5678",
      "state": "處理中",
      "state_code": 5,
      "state_label": "processing",
      "can_modify": 0,
      "user_notified_broker": true,
      "stocks": [
        { "code": "700", "name": "騰訊控股", "amount": "200", "state": 0, "state_label": "processing" }
      ],
      "created_at": "2026-11-05T10:15:00+08:00",
      "days_in_process": 21
    }
  ],
  "total": 1
}
```

### 按市場和狀態篩選

```bash
# 仍在處理中（狀態 5）的港股轉入
longbridge stock-transfers-in --market HK --state 5
```

### 按創建日期篩選

```bash
longbridge stock-transfers-in --start 2026-10-01 --end 2026-10-31
```

### 翻頁

```bash
longbridge stock-transfers-in --page 2 --size 50
```

## 參數

| 參數 | 說明 |
| --- | --- |
| `--market` | `HK`、`US`、`CN` 或 `SG`（預設全部） |
| `--state` | 狀態碼：`0` 已提交，`1` 已撤銷，`3` 已完成（已入倉），`5` 處理中，`7` 部分完成，`8` 失敗（預設全部） |
| `--start`、`--end` | 創建日期範圍，`yyyy-mm-dd`（香港日期）或 RFC 3339 |
| `--page` | 頁碼（預設 1） |
| `--size` | 每頁條數（預設 20，最大 50） |

## 輸出字段

`records[]` 中每項包含：

| 字段 | 說明 |
| --- | --- |
| `id`、`order_id` | 申請 id 及單號 |
| `market` | 股票所屬市場 |
| `broker`、`broker_en`、`code` | 對方券商名稱、英文名稱及券商代碼 |
| `account` | 你在對方券商的賬號，**脫敏為僅顯示後 4 位** |
| `state`、`state_code`、`state_label` | 狀態文案、狀態碼及標籤（`submitted` / `cancelled` / `completed` / `processing` / `partially_completed` / `failed`） |
| `can_modify` | 為 `1` 表示仍可在 App 內撤銷或修改 |
| `app_state`、`user_notified_broker` | `user_notified_broker` 為 `true` 表示你已在 App 內點擊「我已通知」轉出券商——這是你自己的確認，不是 Longbridge 的操作 |
| `stocks[]` | 每隻股票的 `code`、`name`、`amount`、`state`、`state_label`（`processing` / `succeeded` / `failed`） |
| `created_at`、`updated_at`、`process_at`、`exec_at` | 各時間點；未設置的佔位值不輸出 |
| `days_in_process` | 自創建到執行的天數；已撤銷或失敗的算到結束時，未結束的算到今天 |
| `remark`、`reason` | 失敗或撤銷原因（如有） |

`total` 為符合條件的記錄數。賬戶持有人姓名、聯繫方式及證明文件不會輸出。

## 權限要求

需要 OAuth 賬戶權限。參見[賬戶權限設置](/zh-HK/docs/trade/trade-overview)。
