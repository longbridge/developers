# longbridge portfolio

取得完整投資組合概覽——總盈虧、總資產、各市場（美股/港股/A 股/新加坡）市值，以及現金餘額。

:::info Longbridge US 賬戶
在美股數據中心賬戶上，`portfolio` 的 `--format json` 輸出與 AP 賬戶結構一致。`overview` 僅包含 `currency`、`total_asset` 和 `total_cash`（賬戶未返回淨清算價值時沒有 `total_asset`）,`holdings` 即 [`positions`](/zh-HK/docs/cli/account/positions) 的記錄。AP 的 `market_accounts` 以及盈虧、保證金和風險欄位沒有美股數據來源，會省略；賬戶類型、購買力與保證金狀態位於 `us` 下。
:::

## 示例

### 查看投資組合摘要

```bash
longbridge portfolio
longbridge portfolio --format json
```

展示總資產價值、總盈虧及今日盈虧，以及各市場市值分佈。

### 融券保證金明細

```bash
longbridge portfolio short-margin
```

顯示帳戶的融券保證金明細，包含各持倉的保證金要求及存入金額。

## 權限要求

需要 OAuth 帳戶權限。參見[帳戶權限設置](/zh-HK/docs/trade/trade-overview)。
