獲取美股賬戶的購買力、各幣種現金餘額和保證金狀態。

## Schemas

### USCashAndBuyPower

<a id="USCashAndBuyPower"></a>

| 名稱 | 類型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| buy_limit_info | [USBuyLimitInfo](#USBuyLimitInfo) | 是 | 購買力 |
| cash_list | [USCashDetail](#USCashDetail)[] | 是 | 按幣種分列的現金餘額 |
| margin_status | [USMarginStatus](#USMarginStatus) | 是 | 保證金賬戶狀態 |

### USBuyLimitInfo

<a id="USBuyLimitInfo"></a>

| 名稱 | 類型 | 描述 |
| ---- | ---- | ---- |
| currency | string | 貨幣 |
| cash_buy_power | string | 現金購買力 |
| overnight_buy_power | string | 隔夜購買力 |
| day_trade_buy_power | string | 日內交易購買力 |
| instant_buy_power | string | 即時購買力 |
| intraday_margin_buy_power | string | 日內保證金購買力 |
| option_buy_power | string | 期權購買力 |
| crypto_buy_power | string | 加密貨幣購買力 |
| mme | string | 用於計算購買力的維持保證金盈餘 |

### USCashDetail

<a id="USCashDetail"></a>

| 名稱 | 類型 | 描述 |
| ---- | ---- | ---- |
| currency | string | 貨幣 |
| total_amount | string | 現金總額 |
| available_cash | string | 可用現金 |
| withdraw_cash | string | 可取現金 |
| frozen_cash | string | 待成交訂單凍結的現金 |
| settled_cash | string | 已結算現金 |
| outstanding | string | 未結算金額 |
| external_amount | string | 新股認購或基金申購佔用的金額 |

### USMarginStatus

<a id="USMarginStatus"></a>

| 名稱 | 類型 | 描述 |
| ---- | ---- | ---- |
| currency | string | 貨幣 |
| nlv | string | 淨清算價值 |
| margin_equity | string | 保證金權益 |
| margin_maintenance_excess | string | 維持保證金盈餘 |
| mmr | string | 維持保證金要求 |
| reg_t_excess | string | Reg T 盈餘 |
| sma | string | 特別備忘賬戶（SMA） |
