分頁獲取美股賬戶的交易流水，包括存取款、交易、公司行動、轉倉、融資等。

<SDKLinks module="trade" klass="TradeContext" method="us_transaction_history" />

</tbody>

## Parameters

> Content-Type: application/json; charset=utf-8
>
> SDK 方法使用 `start_at` 和 `end_at`（日期時間類型）代替 `start` 和 `end`，其餘參數同名。

| 名稱 | 類型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| start | integer | 是 | 開始時間（Unix 秒），包含 |
| end | integer | 是 | 結束時間（Unix 秒），包含 |
| page | integer | 否 | 頁碼，從 `1` 開始（默認：`1`） |
| size | integer | 否 | 每頁數量（默認：`20`） |
| types | string[] | 否 | 要查詢的流水類型，不傳則返回全部類型，見[流水類型](#transaction-types) |
| currency | string | 否 | 按幣種篩選，例如 `USD`，不傳則返回全部幣種 |

### 流水類型

<a id="transaction-types"></a>

| 取值 | 描述 |
| ---- | ---- |
| `TT_DEPOSIT_AND_WITHDRAWAL` | 存取款 |
| `TT_STOCKS_AND_ETFS_TRADING` | 股票和 ETF 交易 |
| `TT_OPTIONS_TRADING` | 期權交易 |
| `TT_CRYPTO_TRADING` | 加密貨幣交易 |
| `TT_CORPORATE_ACTION` | 公司行動 |
| `TT_TRANSFER_IN_AND_OUT` | 轉入轉出 |
| `TT_CRYPTO_TRANSFER` | 加密貨幣轉賬 |
| `TT_MARGIN_FINANCING` | 融資 |
| `TT_OTHER` | 其他 |

use std::sync::Arc;
use longbridge::{
    oauth::OAuthBuilder,
    trade::{GetUSTransactionHistoryOptions, TradeContext},
    Config,
};
use time::macros::datetime;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let oauth = OAuthBuilder::new("your-client-id").build(|url| println!("Open: {url}")).await?;
    let config = Arc::new(Config::from_oauth(oauth));
    let ctx = TradeContext::new(config);
    let mut opts = GetUSTransactionHistoryOptions::new(
        datetime!(2026-01-01 0:00 UTC),
        datetime!(2026-03-31 0:00 UTC),
    );
    opts.types = vec![
        "TT_DEPOSIT_AND_WITHDRAWAL".to_string(),
        "TT_STOCKS_AND_ETFS_TRADING".to_string(),
    ];
    let resp = ctx.us_transaction_history(opts).await?;
    println!("{:?}", resp);
    Ok(())
}

## Schemas

### USTransactionHistory

<a id="USTransactionHistory"></a>

| 名稱 | 類型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| current_page | integer | 是 | 當前頁碼 |
| items | [USTransaction](#USTransaction)[] | 是 | 本頁記錄 |

### USTransaction

<a id="USTransaction"></a>

| 名稱 | 類型 | 描述 |
| ---- | ---- | ---- |
| title | string | 展示標題 |
| biz_code | string | 業務代碼 |
| biz_code_name | string | 業務代碼名稱 |
| amount | string | 金額，流出時為負數 |
| currency | string | 貨幣 |
| symbol | string | 關聯的標的代碼，例如 `AAPL.US`（僅當記錄與證券相關時返回） |
| market | string | 市場 |
| equity_type | string | 持倉類型 |
| position_side | string | 持倉方向 |
| quantity | string | 數量 |
| quantity_description | string | 數量描述 |
| ref_no | string | 參考編號 |
| remark | string | 備註 |
| create_at | integer | 創建時間（Unix 秒） |
| done_at | integer | 完成時間（Unix 秒） |
