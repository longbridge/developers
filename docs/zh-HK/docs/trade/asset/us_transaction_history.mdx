此方法僅適用於美國數據中心賬戶。
:::

分頁獲取美股賬戶的交易流水，包括存取款、交易、公司行動、轉倉、融資等。

<SDKLinks module="trade" klass="TradeContext" method="us_transaction_history" />

<table className="http-basic">

</tbody>

## Parameters

> Content-Type: application/json; charset=utf-8
>
> SDK 方法使用 `start_at` 和 `end_at`（日期時間類型）代替 `start` 和 `end`，其餘參數同名。

| 名稱 | 類型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| start | integer | 是 | 開始時間（Unix 秒），包含 |
| end | integer | 是 | 結束時間（Unix 秒），包含 |
| page | integer | 否 | 頁碼，從 `1` 開始（默認：`1`） |
| size | integer | 否 | 每頁數量（默認：`20`） |
| types | string[] | 否 | 要查詢的流水類型，不傳則返回全部類型，見[流水類型](#transaction-types) |
| currency | string | 否 | 按幣種篩選，例如 `USD`，不傳則返回全部幣種 |

### 流水類型

<a id="transaction-types"></a>

| 取值 | 描述 |
| ---- | ---- |
| `TT_DEPOSIT_AND_WITHDRAWAL` | 存取款 |
| `TT_STOCKS_AND_ETFS_TRADING` | 股票和 ETF 交易 |
| `TT_OPTIONS_TRADING` | 期權交易 |
| `TT_CRYPTO_TRADING` | 加密貨幣交易 |
| `TT_CORPORATE_ACTION` | 公司行動 |
| `TT_TRANSFER_IN_AND_OUT` | 轉入轉出 |
| `TT_CRYPTO_TRANSFER` | 加密貨幣轉賬 |
| `TT_MARGIN_FINANCING` | 融資 |
| `TT_OTHER` | 其他 |

## Response

響應不返回總條數。當某頁返回的記錄數少於 `size` 時，即為最後一頁。

## Schemas

### USTransactionHistory

<a id="USTransactionHistory"></a>

| 名稱 | 類型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| current_page | integer | 是 | 當前頁碼 |
| items | [USTransaction](#USTransaction)[] | 是 | 本頁記錄 |

### USTransaction

<a id="USTransaction"></a>

| 名稱 | 類型 | 描述 |
| ---- | ---- | ---- |
| title | string | 展示標題，例如 `VA Sell Success: ETHUSD` |
| biz_code | string | 業務代碼，例如 `LVASAD`，參見[業務代碼](#biz-codes) |
| biz_code_name | string | 業務代碼的展示名稱，例如 `VA Sell Success` |
| amount | string | 金額 |
| currency | string | 貨幣，例如 `USD`；可能為空，例如加密貨幣轉入 |
| symbol | string | `TICKER.MARKET` 格式的標的代碼，例如 `MULL.US` 或 `BTCUSD.BKKT`（僅當記錄與證券相關時返回）。此處加密貨幣代碼帶 `.BKKT` 後綴；[美股資產概覽](/zh-HK/docs/trade/asset/us_asset_overview)的 `crypto_list` 則返回不帶後綴的 `BTCUSD` |
| counter_id | string | 與 `symbol` 一同返回的內部標的標識，例如 `VA/BKKT/BTCUSD`。由 HTTP 接口返回，SDK 類型中可能未包含 |
| market | string | 市場，例如 `US` 或 `BKKT` |
| equity_type | string | 持倉類型，例如 `STOCK`、`OPTION`、`CRYPTO` |
| position_side | string | 持倉方向：`LONG` \| `SHORT` |
| quantity | string | 數量 |
| quantity_description | string | 數量描述 |
| ref_no | string | 參考編號 |
| remark | string | 備註 |
| create_at | string | 創建時間，以數字字符串表示的 Unix 秒；SDK 返回日期時間類型 |
| done_at | string | 完成時間，以數字字符串表示的 Unix 秒；SDK 返回日期時間類型 |

### 業務代碼

<a id="biz-codes"></a>

`biz_code` 標識記錄的類型。生產環境中出現過的取值包括：

| biz_code | 描述 |
| -------- | ---- |
| `LVABAD` | 加密貨幣買入成交（`biz_code_name`：`VA Buy Success`） |
| `LVASAD` | 加密貨幣賣出成交（`biz_code_name`：`VA Sell Success`） |
| `LVAVNSCR` | 加密貨幣轉入（`biz_code_name`：`Cryptocurrency Deposit`） |
| `LCSTBD` | 生產環境中出現過，展示名稱以 `biz_code_name` 為準 |
| `LCWD` | 生產環境中出現過，展示名稱以 `biz_code_name` 為準 |

以上列表並不完整，可能出現其他取值。`title` 和 `biz_code_name` 為展示文本，語言可能不同，程序邏輯請使用 `biz_code` 判斷。
