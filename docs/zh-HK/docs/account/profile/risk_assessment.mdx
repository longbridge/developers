獲取 access token 所屬會員的風險評估（合適性問卷）檔案：最近一次問卷的風險等級與得分、專業投資者（PI）狀態，以及 `approvals` 中各項的狀態。

以下欄位的取值由賬戶系統定義，而非本接口定義，接口原樣返回：

- `risk` 是最近一次問卷的風險等級字串（例如 `A5`）。本接口不定義等級集合，也不定義等級之間的順序，請勿據此推斷風險承受能力的高低。
- `pi` 是專業投資者狀態碼。本接口不定義其取值含義，請當作不透明識別碼處理。
- `pi_end_at` 與 `deadlines` 是服務端返回的原始整數。本接口不定義其單位（秒或毫秒），將非 0 值轉換為時間之前請先確認單位。

`approvals` 與 `deadlines` 都以項為鍵。`approvals` 的值是字串而非布林值：`is_corporate_client` 返回 `"false"` / `"true"`，請比較字串，不要直接做真假判斷。

整數欄位可能以 JSON 字串返回（例如 `"pi_end_at": "0"`），這是網關按 proto3 JSON 序列化 int64 的方式。官方 SDK 兩種形式都能解析，並統一以整數暴露。

```cpp
#include <iostream>
#include <longbridge.hpp>

#ifdef WIN32
#include <windows.h>
#endif

using namespace longbridge;
using namespace longbridge::trade;

static void
run(const OAuth& oauth)
{
    Config config = Config::from_oauth(oauth);
    TradeContext ctx = TradeContext::create(config);

    ctx.risk_assessment([](auto res) {
        if (!res) { std::cout << "failed" << std::endl; return; }
        std::cout << "risk: " << res->risk << std::endl;
    });
}

int main(int argc, char const* argv[]) {
#ifdef WIN32
    SetConsoleOutputCP(CP_UTF8);
#endif

    const std::string client_id = "your-client-id";
    OAuthBuilder(client_id).build(
    [](const std::string& url) {
        std::cout << "Open this URL to authorize: " << url << std::endl;
    },
    [](auto res) {
        if (!res) {
            std::cout << "authorization failed: " << *res.status().message() << std::endl;
            return;
        }
        run(*res);
    });

    std::cin.get();
    return 0;
}
```

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/longbridge/openapi-go/config"
	"github.com/longbridge/openapi-go/oauth"
	"github.com/longbridge/openapi-go/trade"
)

func main() {
	o := oauth.New("your-client-id").
		OnOpenURL(func(url string) { fmt.Println("Open this URL to authorize:", url) })
	if err := o.Build(context.Background()); err != nil {
		log.Fatal(err)
	}
	conf, err := config.New(config.WithOAuthClient(o))
	if err != nil {
		log.Fatal(err)
	}
	tctx, err := trade.NewFromCfg(conf)
	if err != nil {
		log.Fatal(err)
	}
	defer tctx.Close()
	ra, err := tctx.RiskAssessment(context.Background())
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%+v\n", ra)
}
```

## Response

### Response Headers

- Content-Type: application/json

### Response Example


## Schemas

### risk_assessment_rsp

<a id="schemarisk_assessment_rsp"></a>

| Name                 | Type     | Required | Description                                                                                                                       |
| -------------------- | -------- | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| risk                 | string   | 否       | 最近一次問卷的風險等級，例如 `A5`。原樣返回；本接口不定義等級集合，也不定義等級之間的順序。可能為空。                              |
| pi                   | int32    | 否       | 專業投資者（PI）狀態碼，原樣返回。本接口不定義其取值含義。                                                                         |
| approvals            | object   | 否       | 各項的狀態，以項名為鍵、字串為值，例如 `car` / `cka` / `risk_audit` → `pass`。值是字串而非布林值：`is_corporate_client` 返回 `"false"` / `"true"`。 |
| re_authentication    | string   | 否       | 重新認證標記，原樣返回。可能為空。                                                                                             |
| pi_end_at            | int64    | 否       | 專業投資者狀態的結束時間，以原始整數返回，未設置時為 `0`。本接口不定義其單位（秒或毫秒）。可能以 JSON 字串返回。                   |
| deadlines            | object   | 否       | `deadlines` 中各項的值，以項名為鍵、整數為值。為原始整數，單位與 `pi_end_at` 一樣未被定義。                                          |
| risk_assessment_at   | string   | 否       | 服務端返回的最近一次評估日期，例如 `2026-10-14`。可能為空。                                                                        |
| score                | int32    | 否       | 問卷得分                                                                                                                           |
| strategy_risk_levels | string[] | 否       | 會員的策略風險等級                                                                                                                 |
