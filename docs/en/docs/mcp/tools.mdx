# Tools

Longbridge MCP exposes 160+ tools. Your client discovers them automatically on connect, and the AI picks the right tool for each request — you don't need to call tools by name.

Actual tool availability depends on your region, account level, and granted OAuth scopes. Trading tools are not available in the ChatGPT App or the Claude directory connector; see [Connect Your Client](/docs/mcp/setup).
