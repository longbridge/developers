Get the risk assessment (suitability questionnaire) profile of the member the access token
belongs to: the risk level
and score of the latest questionnaire, the professional investor (PI) status, and the approval state
of each item.

The vocabularies of several fields are defined by the account system, not by this API, and are
returned as-is:

- `risk` is the risk level string of the latest questionnaire (e.g. `A5`). This API does not define
  the set of levels or any ordering between them, so do not infer that one level means a higher or
  lower risk tolerance than another.
- `pi` is a professional investor status code. This API does not define its code values; treat it as
  an opaque identifier.
- `pi_end_at` and `deadlines` are the raw integers returned by the server. This API does not define
  their unit (seconds or milliseconds), so confirm the unit before converting a non-zero value into a
  timestamp.

`approvals` and `deadlines` are keyed by item. The values of `approvals` are strings,
not booleans: `is_corporate_client` arrives as `"false"` / `"true"`, so compare the string instead of
testing it for truthiness.

Integer fields may arrive as JSON strings (e.g. `"pi_end_at": "0"`), which is how the gateway
serialises int64 in proto3 JSON. The official SDKs accept both forms and expose integers.

#include <iostream>
#include <longbridge.hpp>

#ifdef WIN32
#include <windows.h>

using namespace longbridge;
using namespace longbridge::trade;

static void
run(const OAuth& oauth)
{
    Config config = Config::from_oauth(oauth);
    TradeContext ctx = TradeContext::create(config);

    ctx.risk_assessment([](auto res) {
        if (!res) { std::cout << "failed" << std::endl; return; }
        std::cout << "risk: " << res->risk << std::endl;
    });
}

int main(int argc, char const* argv[]) {
#ifdef WIN32
    SetConsoleOutputCP(CP_UTF8);

    const std::string client_id = "your-client-id";
    OAuthBuilder(client_id).build(
    [](const std::string& url) {
        std::cout << "Open this URL to authorize: " << url << std::endl;
    },
    [](auto res) {
        if (!res) {
            std::cout << "authorization failed: " << *res.status().message() << std::endl;
            return;
        }
        run(*res);
    });

    std::cin.get();
    return 0;
}

package main

import (

	if err != nil {
		log.Fatal(err)
	}
	tctx, err := trade.NewFromCfg(conf)
	if err != nil {
		log.Fatal(err)
	}
	defer tctx.Close()
	ra, err := tctx.RiskAssessment(context.Background())
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%+v\n", ra)
}

## Schemas

### risk_assessment_rsp

<a id="schemarisk_assessment_rsp"></a>

| Name                 | Type              | Required | Description                                                                                                                                                                              |
| -------------------- | ----------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| risk                 | string            | false    | Risk level of the latest questionnaire, e.g. `A5`. Returned as-is; this API does not define the set of levels or an ordering between them. May be empty.                                   |
| pi                   | int32             | false    | Professional investor (PI) status code, returned as-is. This API does not define its code values.                                                                                          |
| approvals            | object            | false    | Approval state per item, keyed by item name with string values, e.g. `car` / `cka` / `risk_audit` → `pass`. The values are strings, not booleans: `is_corporate_client` arrives as `"false"` / `"true"`. |
| re_authentication    | string            | false    | Re-authentication flag, returned as-is. May be empty.                                                                                                                                |
| pi_end_at            | int64             | false    | End time of the professional investor status, returned as the raw integer; `0` when not set. This API does not define the unit (seconds or milliseconds). May arrive as a JSON string.      |
| deadlines            | object            | false    | The `deadlines` entries, keyed by item name with integer values. Raw integers with the same undefined unit as `pi_end_at`.                                                         |
| risk_assessment_at   | string            | false    | Date of the latest assessment as returned by the server, e.g. `2026-10-14`. May be empty.                                                                                                  |
| score                | int32             | false    | Questionnaire score                                                                                                                                                                        |
| strategy_risk_levels | string[]          | false    | Strategy risk levels of the member                                                                                                                                                         |
