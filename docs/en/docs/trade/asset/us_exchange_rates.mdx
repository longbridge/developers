## Response

The HTTP API returns the rates as a two-level map: `universal_exchanges` maps a grouping key to an object whose `spec_exchanges` maps a second grouping key to a list of rates.

The SDKs flatten this map into a single `exchanges` list. Each entry carries the two grouping keys as `universal_key` and `spec_key`, alongside the rate fields.

### Response Example

HTTP API:

```json
{
  "universal_exchanges": {
    "1": {
      "spec_exchanges": {
        "1": {
          "exchanges": [
            {
              "base_currency": "USD",
              "other_currency": "HKD",
              "bid_rate": "7.7850",
              "offer_rate": "7.7950",
              "average_rate": "7.7900"
            }
          ]
        }
      }
    }
  }
}
```

SDK (flattened):

```json
{
  "exchanges": [
    {
      "universal_key": "1",
      "spec_key": "1",
      "base_currency": "USD",
      "other_currency": "HKD",
      "bid_rate": "7.7850",
      "offer_rate": "7.7950",
      "average_rate": "7.7900"
    }
  ]
}
```

### Response Status

| Status | Description | Schema |
| ------ | ----------- | ------ |
| 200    | Success     | [USExchangeRates](#USExchangeRates) |
| 400    | Bad request | None   |

## Schemas

### USExchangeRates

<a id="USExchangeRates"></a>

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| universal_exchanges | map&lt;string, [USUniversalExchanges](#USUniversalExchanges)&gt; | true | Exchange rates, grouped by a first grouping key |

### USUniversalExchanges

<a id="USUniversalExchanges"></a>

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| spec_exchanges | map&lt;string, [USSpecExchanges](#USSpecExchanges)&gt; | true | Exchange rates, grouped by a second grouping key |

### USSpecExchanges

<a id="USSpecExchanges"></a>

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| exchanges | [USExchangeRate](#USExchangeRate)[] | true | Exchange rates in this group |

### USExchangeRate

<a id="USExchangeRate"></a>

| Name | Type | Description |
| ---- | ---- | ----------- |
| base_currency | string | Base currency |
| other_currency | string | Quote currency |
| bid_rate | string | Bid rate. The HTTP API may return it as a number; the SDKs always return a string |
| offer_rate | string | Offer rate. The HTTP API may return it as a number; the SDKs always return a string |
| average_rate | string | Average rate. The HTTP API may return it as a number; the SDKs always return a string |

In the SDK response, each `exchanges` entry also has:

| Name | Type | Description |
| ---- | ---- | ----------- |
| universal_key | string | The `universal_exchanges` grouping key the rate came from |
| spec_key | string | The `spec_exchanges` grouping key the rate came from |
