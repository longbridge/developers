## Response

The HTTP API returns the rates as a two-level map:

- The outer key of `universal_exchanges` is the account channel, e.g. `us_lb_apex`.
- The inner key of `spec_exchanges` is the rate type, e.g. `am` or `reference`.

Other keys may appear, so iterate over the maps rather than hard-coding the keys. The rate fields are JSON numbers in the HTTP API.

The SDKs flatten this map into a single `exchanges` list. Each entry carries the two keys as `universal_key` and `spec_key`, alongside the rate fields, and returns the rates as strings.

## Schemas

### USExchangeRates

<a id="USExchangeRates"></a>

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| universal_exchanges | map&lt;string, [USUniversalExchanges](#USUniversalExchanges)&gt; | true | Exchange rates keyed by account channel, e.g. `us_lb_apex` |

### USUniversalExchanges

<a id="USUniversalExchanges"></a>

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| spec_exchanges | map&lt;string, [USSpecExchanges](#USSpecExchanges)&gt; | true | Exchange rates keyed by rate type, e.g. `am` or `reference` |

### USSpecExchanges

<a id="USSpecExchanges"></a>

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| exchanges | [USExchangeRate](#USExchangeRate)[] | true | Exchange rates of this rate type |

### USExchangeRate

<a id="USExchangeRate"></a>

| Name | Type | Description |
| ---- | ---- | ----------- |
| base_currency | string | Base currency |
| other_currency | string | Quote currency |
| bid_rate | number | Bid rate. The SDKs return it as a string |
| offer_rate | number | Offer rate. The SDKs return it as a string |
| average_rate | number | Average rate. The SDKs return it as a string |

In the SDK response, each `exchanges` entry also has:

| Name | Type | Description |
| ---- | ---- | ----------- |
| universal_key | string | The account channel the rate came from (the `universal_exchanges` key), e.g. `us_lb_apex` |
| spec_key | string | The rate type the rate came from (the `spec_exchanges` key), e.g. `am` or `reference` |
