:::warning Longbridge US Accounts
This method is only available for US data-center accounts.
:::

Get the buying power, per-currency cash balances, and margin status of a US account.

<SDKLinks module="trade" klass="TradeContext" method="us_cash_and_buy_power" />

package main

import (
	"context"
	"fmt"
	"log"

	"github.com/longbridge/openapi-go/config"
	"github.com/longbridge/openapi-go/oauth"
	"github.com/longbridge/openapi-go/trade"
)

func main() {
	o := oauth.New("your-client-id").
		OnOpenURL(func(url string) { fmt.Println("Open this URL to authorize:", url) })
	if err := o.Build(context.Background()); err != nil {
		log.Fatal(err)
	}
	conf, err := config.New(config.WithOAuthClient(o))
	if err != nil {
		log.Fatal(err)
	}
	c, err := trade.NewFromCfg(conf)
	if err != nil {
		log.Fatal(err)
	}
	defer c.Close()
	resp, err := c.USCashAndBuyPower(context.Background(), "USD")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%+v\n", resp)
}

## Schemas

### USCashAndBuyPower

<a id="USCashAndBuyPower"></a>

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| buy_limit_info | [USBuyLimitInfo](#USBuyLimitInfo) | true | Buying power |
| cash_list | [USCashDetail](#USCashDetail)[] | true | Cash balances by currency |
| margin_status | [USMarginStatus](#USMarginStatus) | true | Margin account status |

### USBuyLimitInfo

<a id="USBuyLimitInfo"></a>

| Name | Type | Description |
| ---- | ---- | ----------- |
| currency | string | Currency |
| cash_buy_power | string | Cash buying power |
| overnight_buy_power | string | Overnight buying power |
| day_trade_buy_power | string | Day-trade buying power |
| instant_buy_power | string | Instant buying power |
| intraday_margin_buy_power | string | Intraday margin buying power |
| option_buy_power | string | Option buying power |
| crypto_buy_power | string | Crypto buying power |
| mme | string | Margin maintenance excess used for buying power |

### USCashDetail

<a id="USCashDetail"></a>

| Name | Type | Description |
| ---- | ---- | ----------- |
| currency | string | Currency |
| total_amount | string | Total cash |
| available_cash | string | Available cash |
| withdraw_cash | string | Withdrawable cash |
| frozen_cash | string | Cash frozen for pending orders |
| settled_cash | string | Settled cash |
| outstanding | string | Outstanding (unsettled) amount |
| external_amount | string | Amount held for IPO or fund subscriptions |

### USMarginStatus

<a id="USMarginStatus"></a>

| Name | Type | Description |
| ---- | ---- | ----------- |
| currency | string | Currency |
| nlv | string | Net liquidation value |
| margin_equity | string | Margin equity |
| margin_maintenance_excess | string | Margin maintenance excess |
| mmr | string | Maintenance margin requirement |
| reg_t_excess | string | Regulation T excess |
| sma | string | Special memorandum account (SMA) |
