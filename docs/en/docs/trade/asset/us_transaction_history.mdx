:::warning Longbridge US Accounts
This method is only available for US data-center accounts.
:::

Get the transaction history of a US account (deposits and withdrawals, trades, corporate actions, transfers, margin financing, and so on), one page at a time.

<SDKLinks module="trade" klass="TradeContext" method="us_transaction_history" />

## Parameters

> Content-Type: application/json; charset=utf-8
>
> The SDK method takes `start_at` and `end_at` (date-time values) instead of `start` and `end`; the other parameters use the same names.

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| start | integer | YES | Start time (Unix seconds), inclusive |
| end | integer | YES | End time (Unix seconds), inclusive |
| page | integer | NO | Page number, starting at `1` (default: `1`) |
| size | integer | NO | Page size (default: `20`) |
| types | string[] | NO | Transaction types to include; omit for all types. See [Transaction Types](#transaction-types) |
| currency | string | NO | Currency filter, e.g. `USD`; omit for all currencies |

### Transaction Types

<a id="transaction-types"></a>

| Value | Description |
| ----- | ----------- |
| `TT_DEPOSIT_AND_WITHDRAWAL` | Deposits and withdrawals |
| `TT_STOCKS_AND_ETFS_TRADING` | Stock and ETF trading |
| `TT_OPTIONS_TRADING` | Option trading |
| `TT_CRYPTO_TRADING` | Crypto trading |
| `TT_CORPORATE_ACTION` | Corporate actions |
| `TT_TRANSFER_IN_AND_OUT` | Transfers in and out |
| `TT_CRYPTO_TRANSFER` | Crypto transfers |
| `TT_MARGIN_FINANCING` | Margin financing |
| `TT_OTHER` | Other |

## Response

The response does not include a total count. A page with fewer items than `size` is the last page.

In the HTTP API, `create_at` and `done_at` are Unix seconds encoded as numeric strings (for example `"1790203596"`); the SDKs convert them to date-time values.

## Schemas

### USTransactionHistory

<a id="USTransactionHistory"></a>

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| current_page | integer | true | Current page number |
| items | [USTransaction](#USTransaction)[] | true | Records on this page |

### USTransaction

<a id="USTransaction"></a>

| Name | Type | Description |
| ---- | ---- | ----------- |
| title | string | Display title, e.g. `VA Sell Success: ETHUSD` |
| biz_code | string | Business code, e.g. `LVASAD`. See [Business Codes](#biz-codes) |
| biz_code_name | string | Display name of the business code, e.g. `VA Sell Success` |
| amount | string | Amount |
| currency | string | Currency, e.g. `USD`; may be empty, e.g. for a crypto deposit |
| symbol | string | Security symbol in `TICKER.MARKET` form, e.g. `MULL.US` or `BTCUSD.BKKT`, when the record relates to a security. Crypto symbols carry the `.BKKT` suffix here, unlike `crypto_list` in [US Asset Overview](/docs/trade/asset/us_asset_overview), which returns the bare `BTCUSD` |
| counter_id | string | Internal security identifier returned alongside `symbol`, e.g. `VA/BKKT/BTCUSD`. Returned by the HTTP API; the SDK types may not expose it |
| market | string | Market, e.g. `US` or `BKKT` |
| equity_type | string | Holding type, e.g. `STOCK`, `OPTION`, `CRYPTO` |
| position_side | string | Position side: `LONG` \| `SHORT` |
| quantity | string | Quantity |
| quantity_description | string | Quantity description |
| ref_no | string | Reference number |
| remark | string | Remark |
| create_at | string | Creation time, Unix seconds as a numeric string. The SDKs return a date-time value |
| done_at | string | Completion time, Unix seconds as a numeric string. The SDKs return a date-time value |

### Business Codes

<a id="biz-codes"></a>

`biz_code` identifies the kind of record. Values seen in production include:

| biz_code | Description |
| -------- | ----------- |
| `LVABAD` | Crypto buy filled (`biz_code_name`: `VA Buy Success`) |
| `LVASAD` | Crypto sell filled (`biz_code_name`: `VA Sell Success`) |
| `LVAVNSCR` | Crypto deposit (`biz_code_name`: `Cryptocurrency Deposit`) |
| `LCSTBD` | Seen in production; use `biz_code_name` for its display name |
| `LCWD` | Seen in production; use `biz_code_name` for its display name |

The list is not exhaustive, and other codes may appear. `title` and `biz_code_name` are display text whose language can vary, so use `biz_code` in program logic.
