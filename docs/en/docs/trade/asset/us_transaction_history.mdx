:::warning Longbridge US Accounts
This method is only available for US data-center accounts.
:::

Get the transaction history of a US account (deposits and withdrawals, trades, corporate actions, transfers, margin financing, and so on), one page at a time.

<SDKLinks module="trade" klass="TradeContext" method="us_transaction_history" />

## Parameters

> Content-Type: application/json; charset=utf-8
>
> The SDK method takes `start_at` and `end_at` (date-time values) instead of `start` and `end`; the other parameters use the same names.

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| start | integer | YES | Start time (Unix seconds), inclusive |
| end | integer | YES | End time (Unix seconds), inclusive |
| page | integer | NO | Page number, starting at `1` (default: `1`) |
| size | integer | NO | Page size (default: `20`) |
| types | string[] | NO | Transaction types to include; omit for all types. See [Transaction Types](#transaction-types) |
| currency | string | NO | Currency filter, e.g. `USD`; omit for all currencies |

### Transaction Types

<a id="transaction-types"></a>

| Value | Description |
| ----- | ----------- |
| `TT_DEPOSIT_AND_WITHDRAWAL` | Deposits and withdrawals |
| `TT_STOCKS_AND_ETFS_TRADING` | Stock and ETF trading |
| `TT_OPTIONS_TRADING` | Option trading |
| `TT_CRYPTO_TRADING` | Crypto trading |
| `TT_CORPORATE_ACTION` | Corporate actions |
| `TT_TRANSFER_IN_AND_OUT` | Transfers in and out |
| `TT_CRYPTO_TRANSFER` | Crypto transfers |
| `TT_MARGIN_FINANCING` | Margin financing |
| `TT_OTHER` | Other |

```rust
        "TT_DEPOSIT_AND_WITHDRAWAL".to_string(),
        "TT_STOCKS_AND_ETFS_TRADING".to_string(),
    ];
    let resp = ctx.us_transaction_history(opts).await?;
    println!("{:?}", resp);
    Ok(())
}
```

```go
package main

import (
	"context"
	"fmt"
	"log"
	"time"

	"github.com/longbridge/openapi-go/config"
	"github.com/longbridge/openapi-go/oauth"
	"github.com/longbridge/openapi-go/trade"
)

func main() {
	o := oauth.New("your-client-id").
		OnOpenURL(func(url string) { fmt.Println("Open this URL to authorize:", url) })
	if err := o.Build(context.Background()); err != nil {
		log.Fatal(err)
	}
	conf, err := config.New(config.WithOAuthClient(o))
	if err != nil {
		log.Fatal(err)
	}
	c, err := trade.NewFromCfg(conf)
	if err != nil {
		log.Fatal(err)
	}
	defer c.Close()
	resp, err := c.USTransactionHistory(context.Background(), &trade.GetUSTransactionHistory{
		StartAt: time.Date(2026, 1, 1, 0, 0, 0, 0, time.UTC),
		EndAt:   time.Date(2026, 3, 31, 0, 0, 0, 0, time.UTC),
		Page:    1,
		Size:    20,
		Types:   []string{"TT_DEPOSIT_AND_WITHDRAWAL", "TT_STOCKS_AND_ETFS_TRADING"},
	})
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%+v\n", resp)
}
```

## Schemas

### USTransactionHistory

<a id="USTransactionHistory"></a>

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| current_page | integer | true | Current page number |
| items | [USTransaction](#USTransaction)[] | true | Records on this page |

### USTransaction

<a id="USTransaction"></a>

| Name | Type | Description |
| ---- | ---- | ----------- |
| title | string | Display title |
| biz_code | string | Business code |
| biz_code_name | string | Business code name |
| amount | string | Amount; negative for outflows |
| currency | string | Currency |
| symbol | string | Security symbol, e.g. `AAPL.US`, when the record relates to a security |
| market | string | Market |
| equity_type | string | Holding type |
| position_side | string | Position side |
| quantity | string | Quantity |
| quantity_description | string | Quantity description |
| ref_no | string | Reference number |
| remark | string | Remark |
| create_at | integer | Creation time (Unix seconds) |
| done_at | integer | Completion time (Unix seconds) |
