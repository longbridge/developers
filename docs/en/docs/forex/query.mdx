This API is used to query a currency-exchange order by your `client_order_id`.
Poll it until the order reaches a terminal state.

<CliCommand>
longbridge forex order my-order-0001
</CliCommand>

<SDKLinks module="forex" klass="ForexContext" method="order" />

## Request

<table className="http-basic">
<tbody>
<tr><td className="http-basic-key">HTTP Method</td><td>GET</td></tr>
<tr><td className="http-basic-key">HTTP URL</td><td>/v1/forex/order </td></tr>
</tbody>
</table>

### Parameters

> Content-Type: application/json; charset=utf-8

| Name            | Type   | Required | Description     |
| --------------- | ------ | -------- | --------------- |
| client_order_id | string | YES      | Your order id   |

Poll no more often than every 2 seconds. Most orders reach a terminal state
within 1 minute; it can take longer outside service hours or under manual
review.

```cpp
#include <iostream>
#include <longbridge.hpp>

#ifdef WIN32
#include <windows.h>
#endif

using namespace longbridge;
using namespace longbridge::forex;

static void
run(const OAuth& oauth)
{
    Config config = Config::from_oauth(oauth);
    ForexContext ctx = ForexContext::create(config);

    ctx.order("my-order-0001", [](auto res) {
        if (!res) { std::cout << "failed" << std::endl; return; }
        std::cout << "state: " << res->state << std::endl;
    });
}

int main(int argc, char const* argv[]) {
#ifdef WIN32
    SetConsoleOutputCP(CP_UTF8);
#endif

    const std::string client_id = "your-client-id";
    OAuthBuilder(client_id).build(
    [](const std::string& url) {
        std::cout << "Open this URL to authorize: " << url << std::endl;
    },
    [](auto res) {
        if (!res) {
            std::cout << "authorization failed: " << *res.status().message() << std::endl;
            return;
        }
        run(*res);
    });

    std::cin.get();
    return 0;
}
```

  <TabItem value="go" label="Go">

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/longbridge/openapi-go/config"
	"github.com/longbridge/openapi-go/forex"
	"github.com/longbridge/openapi-go/oauth"
)

func main() {
	o := oauth.New("your-client-id").
		OnOpenURL(func(url string) { fmt.Println("Open this URL to authorize:", url) })
	if err := o.Build(context.Background()); err != nil {
		log.Fatal(err)
	}
	conf, err := config.New(config.WithOAuthClient(o))
	if err != nil {
		log.Fatal(err)
	}
	fctx, err := forex.NewFromCfg(conf)
	if err != nil {
		log.Fatal(err)
	}
	defer fctx.Close()
	resp, err := fctx.Order(context.Background(), "my-order-0001")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("state:", resp.State)
}
```

## Response

### Response Headers

- Content-Type: application/json

### Response Example

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "state": 1,
    "rate": "7.7812",
    "from_amount": "1000",
    "to_amount": "7781.2",
    "fail_reason": ""
  }
}
```

The `data` fields are:

| Name        | Type   | Description                                                                                                          |
| ----------- | ------ | ------------------------------------------------------------------------------------------------------------------- |
| state       | int32  | `0` processing (incl. manual review — keep querying); `1` success; `2` failed (frozen funds returned)               |
| rate        | string | Execution rate (standard currency-pair terms); empty when not filled                                                |
| from_amount | string | Convert-out amount (actual once filled)                                                                             |
| to_amount   | string | Convert-in amount (actual once filled)                                                                              |
| fail_reason | string | Failure reason                                                                                                      |

### Response Status

| Status | Description                                              | Schema |
| ------ | -------------------------------------------------------- | ------ |
| 200    | The order was returned successfully.                     | None   |
| 400    | The query failed with an error in the request parameter. | None   |
