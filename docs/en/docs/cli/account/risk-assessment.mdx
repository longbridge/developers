# longbridge risk-assessment

Show your risk assessment profile — the risk level and score of your latest assessment, your professional investor (PI) status, and the approval state of each item.

## Basic Usage

```bash
longbridge risk-assessment
```

```
| Field                      | Value                                                          |
|----------------------------|----------------------------------------------------------------|
| Risk Level                 | A5                                                             |
| Score                      | 0                                                              |
| Assessed At                | 2026-10-14                                                     |
| Professional Investor (PI) | 0                                                              |
| PI End At                  | -                                                              |
| Approvals                  | car=pass, cka=pass, is_corporate_client=false, risk_audit=pass |
| Deadlines                  | -                                                              |
| Re-authentication          | -                                                              |
| Strategy Risk Levels       | -                                                              |
```

The command takes no arguments. Maps render as comma-separated `key=value` pairs, and unset values — empty strings, empty maps or lists, and a `0` PI end time — render as `-`.

## Examples

### Check your current risk profile

```bash
longbridge risk-assessment
# Output as JSON for scripting
longbridge risk-assessment --format json
```

`--format json` prints the full SDK object, with the field names the API returns. Note that
integer fields the gateway serialises as JSON strings (e.g. `"pi_end_at": "0"`) are exposed as
integers here:

```json
{
  "risk": "A5",
  "pi": 0,
  "approvals": {
    "car": "pass",
    "cka": "pass",
    "is_corporate_client": "false",
    "risk_audit": "pass"
  },
  "re_authentication": "",
  "pi_end_at": 0,
  "deadlines": {},
  "risk_assessment_at": "2026-10-14",
  "score": 0,
  "strategy_risk_levels": []
}
```

## Reading the output

Several values come straight from the account system and are printed as-is:

- **Risk Level** (`risk`) is the level string of your latest assessment, e.g. `A5`. The set of levels and any ordering between them are not defined by the API, so do not read one level as higher or lower risk tolerance than another.
- **Professional Investor (PI)** (`pi`) is a status code. Its code values are not defined by the API; treat it as an opaque identifier.
- **PI End At** (`pi_end_at`) and **Deadlines** (`deadlines`) are raw integers. Their unit — seconds or milliseconds — is not defined by the API, so confirm it before converting a non-zero value into a timestamp.
- **Approvals** values are strings, not booleans: `is_corporate_client=false` is the string `"false"`.

## Requirements

A valid OAuth login is required. Run `longbridge auth login` if you have not yet authenticated.
