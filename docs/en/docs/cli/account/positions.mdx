# longbridge positions

List your current stock positions — symbol, quantity, available quantity, cost price, and market.

:::info Longbridge US Accounts
On a US data-center account, `positions` returns the asset overview instead of a stock list. With `--format json`, the output is an object with `account_type`, `cash_buy_power`, `stock_list`, `option_list`, `crypto_list` and `cash_list`. For field meanings, see the [US Asset Overview](/docs/trade/asset/us_asset_overview) API, or run `longbridge positions --schema` to see the output schema.
:::

## Basic Usage

```bash
longbridge positions
```

## Examples

### View all positions

```bash
longbridge positions
longbridge positions --format json
```

Displays every open stock position with its name, symbol, quantity, available quantity for trading, cost price, and market.

## Requirements

OAuth account permission required. See the [account permission setup](/docs/trade/) guide.
