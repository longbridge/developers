# longbridge fund-positions

List your current fund and ETF positions.

## Basic Usage

```bash
longbridge fund-positions
```

```
| Counter ID | Name | Net Asset Value | Cost Net Asset Value | Currency | Holding Units |
|--------|------|-----------------|----------------------|----------|---------------|
```

## Examples

### View fund/ETF holdings

```bash
longbridge fund-positions
longbridge fund-positions --format json
```

Displays all fund and ETF positions in your account, including counter_id, quantity, and cost information.

## Requirements

OAuth account permission required. See the [account permission setup](/docs/trade/) guide.
